# v35.9.33.5 权限与互斥验收

日期：2026-11-26

## owner-only

```text
GET/POST /api/chat/mode
POST /api/chat/mode/approve
非 owner uid -> 403 owner_only
```

## 互斥

```text
状态机只有一个 mode
切 Code -> Shell 会覆盖 Code
切回 Chat 清空 Code 过期时间
非 Agent 清空 agent_task
非 Shell 清空 approval
```

## 不混消息

```text
chat    persona:nao
code    mode:code
agent   mode:agent
shell   mode:shell
```

四种 target 历史独立；记忆通过 memory_target=persona:nao 共享。
