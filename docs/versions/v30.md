# v30.0.0 · LITE 模式

## 为什么需要

浏览器 + OCR 是重依赖：300 MB + 200 MB 内存。小机器或 VPS 上可以不要。

## 开关

```bash
NAO_LITE=1 python3 run.py
```

| 能力 | 完整模式 | LITE |
|---|---|---|
| 聊天 / 记忆 / 情绪 | ✅ | ✅ |
| 看图（多模态） | ✅ | ✅ |
| 语音合成（edge-tts） | ✅ | ❌ |
| 读小说正文 | ✅ OCR | ❌ 只记进度 |
| 刷视频（v23） | ✅ | ❌ |
| 内存占用 | ~500 MB | ~120 MB |

## 实现

| 项 | 做法 |
|---|---|
| 能力探测 | `cfg.CAPABILITIES = {"browser": bool, "ocr": bool, "tts": bool}` |
| 调用处 | 先查能力，没有就跳过并记日志 |
| 提示词 | LITE 下不告诉她「你能看图/读书」 |

## 验收

- [ ] `NAO_LITE=1` 启动不报缺依赖
- [ ] LITE 下聊天、记忆、主动消息全部正常
- [ ] 读书自动降级为「浅层在读」
- [ ] 内存 < 150 MB

# v30.0.1 · ARM / 树莓派适配

## 要验证的

| 项 | 风险 |
|---|---|
| Chromium 在 ARM 是否有包 | 可能要用 `chromium-browser` 系统包 |
| tesseract 中文包 | 有 `tesseract-ocr-chi-sim`，可用 |
| PyMySQL / jieba / Pillow | 纯 Python 或有轮子，应该没问题 |
| 内存 | 4 GB 的树莓派要开 LITE |

## 推荐配置

| 项 | 值 |
|---|---|
| 机器 | 树莓派 4B / 4 GB |
| 系统 | Raspberry Pi OS 64-bit |
| 模式 | `NAO_LITE=1` |
| 存储 | 32 GB TF 卡（日志 + 图片） |

## 验收

- [ ] 树莓派上 `python3 run.py` 能起来
- [ ] 聊天延迟 < 2 秒（不含模型时间）
- [ ] 连续跑 24 小时不 OOM

# v30.0.2 · 一键安装脚本

## 做什么

```bash
curl -fsSL https://raw.githubusercontent.com/<repo>/main/scripts/install.sh | bash
```

| 步骤 | 内容 |
|---|---|
| 1 | 检查 Python / MySQL / git |
| 2 | 拉代码到 `~/NapCat-Pyhon` |
| 3 | 建 `config.local.json`（交互式问 4 个值） |
| 4 | 装依赖（含可选 tesseract / playwright，问要不要） |
| 5 | 跑数据库迁移 |
| 6 | 跑 preflight |
| 7 | 装 systemd unit 并启动 |

## 升级 / 回滚

```bash
nao-bot upgrade     # git pull + 迁移 + 重启
nao-bot rollback    # 回到上一个 tag
nao-bot status      # 状态 + 最近日志
```

## 验收

- [ ] 全新机器一条命令装好并跑起来
- [ ] 升级失败能自动回滚到上一版
- [ ] 卸载干净（不留 systemd unit 和锁文件）
