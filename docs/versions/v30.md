# v30 系列 · 调度层接口实现

> 核心：把进程内 asyncio 调度器包成 `Scheduler` / `Trigger` 实现。
> asyncio 调度器是核心 native，不注册为插件。

```python
class Trigger(Protocol):
    name: str
    async def next_at(self, now): ...


class Scheduler(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def schedule(self, trigger: Trigger, callback) -> str: ...
    async def cancel(self, task_id: str) -> None: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v30.0** | `Scheduler` / `Trigger` 契约 | 业务只依赖接口 |
| **v30.1** | `AsyncioScheduler` native adapter | 现有定时行为不变 |
| **v30.2** | 现有 cron / items 收口到 Scheduler | 任务不重复/不漏 |
| **v30.3** | 第三方 trigger adapter + fake 测试 | 新触发器不改业务 |

## 关键约束

- asyncio 调度器是核心 native，不注册为插件。
- 第三方调度失败由 v32 回退 asyncio。
- 核心调度只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
