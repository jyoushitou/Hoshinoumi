# v30 系列 · 调度层接口

> 核心：只定义第三方调度实现接入的接口。
> 进程内 asyncio 调度器是核心 native 实现，不是插件。

```python
class Trigger(Protocol):
    name: str
    async def next_at(self, now) -> float | None: ...


class Scheduler(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def schedule(self, trigger: Trigger, callback) -> str: ...
    async def cancel(self, task_id: str) -> None: ...
```

规则：

- 核心调度器不注册到插件表；插件只能新增外部 trigger / 队列适配器。
- 插件调度失败时回退进程内 asyncio。
- 核心调度只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
