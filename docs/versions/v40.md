# v40 系列 · 自有客户端（四）手机 App

> 前置：v23（多用户 API）与 v26（Web）已完成｜预估 12 天｜**六个次版本**
>
> 把浏览器里那套搬进手机：能聊、能收推送、能管理她的事，
> 还能**记账**。聊天/推送/面板完全复用 v23 的多用户 API；

## v40.3 · 记账（2 天）

> 目标：手机上 3 秒记一笔；聊天里说一句也能记。
> 只做**手动记账 + 统计**，不接银行、不做投资、不做多人共享账本。

### 数据模型

| 表 | 字段 | 说明 |
|---|---|---|
| `ledger_transactions` | id / user_id / amount / currency / category / note / account / occurred_at / client_id / created_at | 一笔收支；`client_id` 幂等 |
| `ledger_categories` | user_id / name / kind / icon | 自定义分类；首次给默认分类 |
| `ledger_budgets` | user_id / month / category / amount | 月度预算，可选 |

金额用 `DECIMAL(12,2)`，不要用 float；默认币种 `CNY`，先只做单币种。

### API

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/ledger` | 新增一笔（`client_id` 幂等） |
| GET | `/api/ledger?from=&to=&category=` | 列表/筛选 |
| PATCH | `/api/ledger/{id}` | 改金额/分类/备注 |
| DELETE | `/api/ledger/{id}` | 删除 |
| GET | `/api/ledger/summary?month=YYYY-MM` | 月度收支、分类汇总、预算 |
| GET | `/api/ledger/export.csv` | 导出当月 CSV |

`user_id` 一律从 JWT 取，不接受客户端传别人的 id；跨账号查询返回 404。

### App 面板

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 记一笔：金额键盘、分类、备注、日期 | 3 秒内记完 |
| U2 | 本月概览：收入/支出/结余、分类占比 | 一眼看懂钱花哪 |
| U3 | 流水列表：按日分组、编辑、删除 | 能改错账 |
| U4 | 预算：设置月预算，超 80% 提醒 | 不超时不打扰 |
| U5 | 聊天入口：`!账 25 午饭` / “记一笔 25 午饭” | 一句话能记 |
| U6 | 导出 CSV / 分享 | 数据能带走 |

### 红线

- 不接银行/支付账单自动导入；不存卡号、密码、验证码。
- 不做多币种换算、投资、借贷、发票。
- 账目默认只在本账号可见；导出文件由用户自己保存。
- 删除是软删除或二次确认，避免误删。

## 风险

| 风险 | 处理 |
|---|---|
| Flutter 环境重 | 先 Android；iOS 用 PWA |
| 国产 ROM 杀后台 | 引导加白名单；失败就退回 PWA |
| 推送延迟 | 长连接 + 心跳，不依赖系统推送 |
| 金额精度 | 全部 DECIMAL(12,2)，禁止 float；测试四舍五入 |
| 离线记账 | v41 outbox 带 `client_id`，恢复后幂等同步 |
| 隐私 | 不做银行导入；导出文件不进日志/审计 |
