# v40 系列 · 运维与嵌入式（合并）

> 大版本 v40。原 v39 运维 + 原 v41 嵌入式前端合并。
> 先让后端常驻自愈，再让嵌入式屏常亮显示对话。

## 1. 范围

### 运维

```text
systemd 单元 / 自启
worker + ingress 健康检查
崩溃拉起、重启恢复
日志轮转/崩溃留痕
```

### 嵌入式

```text
树莓派/平板 + Chromium kiosk
触摸/软键盘/息屏唤醒
断网/重启恢复
```

不做：

```text
不新起第二套后端
不写原生 App
不把嵌入式当第二套核心
```

## 2. 架构

```text
systemd
  ├─ hoshinoumi-ingress.service
  ├─ hoshinoumi-worker.service
  └─ hoshinoumi-watchdog.timer

Chromium kiosk
  → http://127.0.0.1:5492（Web UI）
  → v35 hub / 本机服务
```

## 4. 约束

```text
unit 只负责拉起，业务仍由 supervisor 管蓝绿
watchdog 不做业务逻辑，只查 health/ready
重启保留 data/ 与 logs/
Chromium kiosk 只加载 Web UI
断网显示最后缓存 + 重连中
触摸目标 ≥44px，软键盘不遮输入框
```

## 5. 风险

```text
systemd 与 supervisor 抢进程：unit 只启动 supervisor/ingress
看门狗误杀：连续 3 次失败才重启
嵌入式性能：限制动画/图片；先文本
断电损坏：SQLite WAL + 只读缓存
```

## 6. 总验收

```text
1. 重启机器后自动恢复
2. kill worker 后 30s 内拉起
3. 嵌入式开机进入对话
4. 断网显示离线，不白屏
5. 触摸/软键盘可用
6. 崩溃日志可查
```
