# v44 系列 · 默认链路层插件接入

> 前置：v43 默认链路层契约 + native adapter。  
> 本版只做第三方 默认链路层实现接入，不重写核心 native。  
> 跨版本总纲：[INTERFACE-PLAN-v27-v44.md](../INTERFACE-PLAN-v27-v44.md)。

## 目标

```text
PluginRegistry 注册 默认链路 adapter
→ 权限 / 错误 / 任务 / 热更走 v28 运行时
→ 调用方 get() 拿不到时回落 核心 native 默认链路
```

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v44.0** | 第三方 `RouteRegistry / FallbackChain` adapter 接入点 + fake 实现 | 不改业务代码即可切换实现 |
| **v44.1** | 权限、错误、任务、热更接入 | 违规调用被拒绝；失败可查 |
| **v44.2** | `!route` 只读视图 + 决策日志 + 回归/文档 | 能解释为什么走 native |

## 能力与约束

- 能力名：`route.<layer>.<name>@1`。
- 核心 native（核心 native 默认链路）不实现 PluginManifest、不进入插件表。
- 默认仍走 native；插件只能作为候选，除非显式路由/配置切换。
- 插件实现 `RouteRegistry / FallbackChain`，通过 v27 `PluginRegistry` 注册。
- 插件任务、线程池、DB 连接池由 v28 context 提供。
- 插件失败写 `plugin_errors`，连续失败自动停用。
- 插件 DDL 只允许 `plugin_<name>_` 前缀，MySQL/SQLite。

## 非目标

- 不重新定义 默认链路层 Protocol（v43 已完成）
- 不把 native 插件化
- 不允许插件改核心默认实现
