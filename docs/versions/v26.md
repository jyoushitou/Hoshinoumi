# v26 系列 · 记忆层接口实现

> 核心：把现有 BM25 / 仓储包成 `MemoryStore` / `Retriever` 实现，并暴露第三方接口。
> BM25 是核心 native，不注册为插件。

```python
class MemoryStore(Protocol):
    async def add(self, user_id: str, item: dict) -> str: ...
    async def delete(self, user_id: str, item_id: str) -> None: ...


class Retriever(Protocol):
    async def search(self, user_id: str, query: str, top_k: int) -> list[dict]: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v26.0** | `MemoryItem` / `MemoryStore` / `Retriever` 契约 | 业务只依赖接口 |
| **v26.1** | `SQLMemoryStore` native adapter（现有 repo_memory） | 现有读写行为不变 |
| **v26.2** | `BM25Retriever` native adapter（现有 retrieval） | 现有召回结果不变 |
| **v26.3** | 第三方 retriever / embedding adapter 接入点 + fake 测试 | 新检索器不改业务 |

## 关键约束

- BM25 是核心 native，不注册为插件。
- 所有接口强制带 `user_id`，禁止跨用户。
- 第三方检索失败/超时由 v32 回退 BM25。
- 核心记忆只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
