# v26 系列 · 记忆层接口

> 核心：只定义第三方记忆实现接入的接口。
> BM25 是核心 native 实现，不是插件。

```python
class MemoryItem(Protocol):
    user_id: str
    text: str
    tags: list[str]
    weight: float


class MemoryStore(Protocol):
    async def add(self, item: MemoryItem) -> str: ...
    async def delete(self, item_id: str) -> None: ...


class Retriever(Protocol):
    async def search(self, user_id: str, query: str, top_k: int) -> list[MemoryItem]: ...


class EmbeddingProvider(Protocol):
    async def embed(self, texts: list[str]) -> list[list[float]]: ...
```

规则：

- BM25 不注册到插件表；插件只能新增可选 retriever / embedding。
- 插件必须带 `user_id` 命名空间，禁止跨用户。
- 核心记忆只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
