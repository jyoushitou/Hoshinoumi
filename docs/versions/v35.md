## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v35.0** | 多端推送：Endpoint / DeliveryHub / 协议 | 两个测试入口 + QQ 能收 |

## 约束

- 所有客户端复用 v35.0 hub 和 v35.1 本机服务。
- 不重写核心；跨端只共享 `memories` / `conversation_messages`。
- 先做 Web，再做桌面/手机；不并行铺开。
