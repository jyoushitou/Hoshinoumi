# v35 系列 · 本机服务化

> 前置：v23 多用户 API / v21 鉴权｜预估 4 天｜**次版本 v35.1**
>
> 目标：把 bot + gateway 变成可常驻的本机服务，供后续 DSH / Qoder /
> WorkBuddy 插件连接。**本版不做插件**。

## 范围

| 做 | 不做 |
|---|---|
| `nao-service` 启动器：守护、重启、日志 | DSH 插件 |
| 开机自启：systemd user / launchd / Windows 计划任务 | Qoder / WorkBuddy |
| 健康检查、端口冲突、重复启动检测 | 公网部署 |
| 服务状态：`nao status` | 新业务功能 |

## 端口

```text
bot 内部 API：127.0.0.1:27004
gateway：    127.0.0.1:27005
```

插件默认直连 27004；跨机才走 27005。

## 验收

```bash
nao-service start
nao-service status
nao-service restart
nao-service stop
```

- 重启机器后服务自动可用。
- 重复启动不会起两份。
- 端口被占用时明确报错，不静默失败。
- 服务挂了能被守护进程拉起。
- QQ 链路和插件服务共用一份后端，不互相抢锁。
