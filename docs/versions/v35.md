# v35 系列 · 工具层契约与 native adapter

> 核心：把现有工具包成 `Tool` 实现，第三方工具接入在 v36。
> 现有工具是核心 native，不注册为插件。

```python
class Tool(Protocol):
    name: str
    schema: dict
    permissions: set[str]
    async def invoke(self, user_id: str, args: dict) -> dict: ...
```

## 本层插件接口约束（v27 总纲）

> 跨版本总纲：[INTERFACE-PLAN-v27-v44.md](../INTERFACE-PLAN-v27-v44.md)

- 本版只开放**工具层**接口，不把其他层一起搬。
- 能力名：`tool.<name>@1`。
- 核心 native（现有工具）保持 native，**不实现 PluginManifest，不进入插件表**。
- 第三方实现本层 Protocol，通过 v27 `PluginRegistry` 注册。
- 业务只依赖 Protocol；`get()` 拿不到时回落核心 native。
- 敏感资源走 v27 权限三档（0 拒绝 / 1 询问 / 2 允许），默认 1。
- 插件任务、线程池、DB 连接池由 v27 context 提供，不允许裸 `create_task` / 裸连库。
- 插件失败写 `plugin_errors`，连续失败自动停用。
- 插件 DDL 走 `migrations/`，只支持 MySQL/SQLite，表前缀 `plugin_<name>_`。
- 热更采用 worker 进程级快照；已启用插件在新 worker 自动加载。

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v35.0** | `ToolSpec` / `Tool` 契约 | 业务只依赖接口 |
| **v35.1** | 现有工具 native adapter，逐个包 | 工具行为不变 |
| **v35.2** | 权限/超时统一入口 | 越权/超时被拒绝 |

> 第三方工具层实现见 [v36.md](v36.md)。

## 关键约束

- 现有工具是核心 native，不注册为插件。
- 第三方工具必须有 schema/权限；失败由 v43 回退核心工具。
- 核心工具只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
