# v36 系列 · DSH 插件

> 前置：v35 本机服务化｜预估 4 天｜**次版本 v36.1**
>
> 目标：让 DSH 里的 agent 通过本机 HTTP 调用她。
> 插件只做协议翻译，不复制业务逻辑。

## 接口

```text
nao.chat(text)       -> bot /internal/chat
nao.remember(text)   -> bot /internal/memory/add
nao.recall(query)    -> bot /internal/memory/search
nao.fact(slot)       -> bot /internal/fact
nao.notify(text)     -> bot 主动消息
```

默认直连：

```text
http://127.0.0.1:27004
```

跨机模式走网关：

```text
https://<gateway>:27005 + Bearer token
```

## 验收

- DSH 能识别插件和工具。
- `nao_chat` / `nao_recall` / `nao_remember` 能调用。
- 后端没起时，插件提示“她暂时不在”，不崩 agent。
- token 只在 gateway 模式使用，不写入 IDE 工程。
- 不缓存聊天原文到工程目录。
