# v36 系列 · 插件增强

> 大版本 v36。目标：第三方开发者可以通过插件修改**完整功能**，而不只是替换模型/记忆/通道 adapter。
> 原 v36 生态接入顺延为 v37；原 v37 运维与嵌入式顺延为 v38。

## 1. 范围

### 要做

```text
插件 API v2：扩展点/钩子/权限/版本
命令插件
聊天前后中间件
prompt 构建钩子
关系/情境策略插件
事件/定时/数据插件
UI 面板插件
插件数据迁移
审计/配额/冲突/回滚
SDK + 示例
```

### 不做

```text
不开放任意 shell
不允许插件绕过权限直接连库
不允许插件写核心表结构
不改变 owner 最终控制权
```

## 2. 核心原则

```text
插件可以改行为，不能拿走控制权
任何扩展点都有 native 默认
插件失败/超时/停用 → 回落 native
所有修改可审计、可回滚
```

## 3. 插件 API v2

```python
class ExtensionPoint(Protocol):
    name: str
    def capabilities(self) -> set[str]: ...

class PluginContext:
    def register_command(self, name, handler, **meta): ...
    def on(self, hook, handler, priority=0): ...
    def middleware(self, hook, handler, priority=0): ...
    def register_panel(self, panel): ...
    def register_job(self, trigger, callback): ...
    def storage(self): ...
    def permissions(self): ...
```

能力名：

```text
core.chat.before_reply@1
core.chat.after_reply@1
core.prompt.build@1
core.relation.adjust@1
core.command.<name>@1
core.event.<name>@1
core.ui.panel.<name>@1
```

## 4. 扩展点

| 扩展点 | 能改什么 | 默认 |
|---|---|---|
| `chat.before_reply` | 改写用户消息/附加上下文 | 原消息 |
| `prompt.build` | 追加/替换 prompt 片段 | 核心 prompt |
| `chat.after_reply` | 改写/拦截回复 | 原回复 |
| `relation.adjust` | 关系加减/策略 | 核心 relation |
| `command` | 新命令/覆盖命令 | 核心命令 |
| `event` | 监听/处理事件 | 核心事件 |
| `job` | 定时任务 | asyncio 调度 |
| `ui.panel` | 客户端面板 | 无 |
| `storage.migration` | 插件表迁移 | 无 |

## 6. 开发思路

### 6.1 先契约，后能力

```text
v36.0 扩展点注册
→ v36.1 聊天/命令/关系
→ v36.2 事件/数据
→ v36.3 UI
→ v36.4 安全
→ v36.5 SDK
```

每个扩展点先有 native 默认，再有插件覆盖。

### 6.2 中间件链

```text
inbound
→ chat.before_reply (priority)
→ prompt.build
→ core model
→ chat.after_reply
→ outbound
```

- 同优先级按插件名稳定排序。
- 单个中间件超时/异常 → 跳过，记录 `plugin_errors`。
- 不允许中间件无限递归。

### 6.3 关系插件

```python
class RelationPolicy(Protocol):
    async def adjust(self, user_id, delta, reason, severity) -> float: ...
```

- 只能加减，不能直接写 1.0。
- 核心 `relation.apply_delta` 仍是默认。
- 每次变化写 `relation_events`，插件名可追溯。
- 插件停用后回到核心规则。

### 6.4 安全

```text
插件是代码，不是配置
只允许 owner 安装/启用
权限默认 1（询问）
网络/DB/命令/关系分权
资源配额 + 超时
审计 + 一键停用
```

不承诺“绝对沙箱”；靠权限、审计、回滚控制风险。

### 6.5 兼容

```text
api_version=1 旧插件继续加载
api_version=2 新扩展点
不兼容版本拒绝，不静默降级
```

## 8. 风险

- 插件改坏核心：native 回落 + 停用 + 审计。
- 权限绕过：所有 context 能力都走 permission。
- 插件冲突：扩展点优先级 + 冲突检测。
- 性能：超时/配额/熔断。
- 生态质量：SDK + 示例 + 审核清单。

## 9. 总验收

```text
1. 示例插件能改回复、加命令、改关系、加面板
2. 插件异常不影响核心聊天
3. 停用插件后行为回 native
4. 越权网络/DB/关系被拒绝
5. 旧 v1 插件仍能加载
6. 审计能查到插件改了什么
7. 全量测试 0 失败
```
