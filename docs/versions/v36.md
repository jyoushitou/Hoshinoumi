## v36.9 内容流

```text
抓公开页 → 正文提取 → 1000 字分块
→ summarize_chapter → book_memory / reading_queue
→ 按 offset 续读
```

源：

```text
weibo   公开微博正文/长文
tieba   贴吧主题帖 + 楼中楼（只读）
zhihu   知乎回答/文章（只读）
```

约束：

- 只读：不发帖、不评论、不点赞。
- Cookie 放 `.env`，不进日志。
- 一页一次，限速；失败换源。
- 复用 `book_queue` 的 offset/status，不另建进度。
- 自动流程只入库，不主动发摘要。

## v36.10 随机消费

```text
本地读书 / 贴吧 / B站 / 微博 / 知乎
```

- 权重可配，读书默认略高。
- 同一 source 不连续选，有冷却。
- 失败/空内容换源，不刷屏。
- 命令才回摘要：`!feed random|tieba|weibo|zhihu|bilibili`、`!book next`。

## 约束

- 每个生态独立开关，默认关闭。
- 写操作必须审批；失败回滚。
- 不把平台密钥写进日志。
