# v36 系列 · 生态接入

> 合并原 v56–v66：QQ 空间、运维、视频、微信、音视频通话、微服务，并新增微博/贴吧/知乎内容流与随机内容消费。

## 内容流与随机消费

### v36.10 复用读书逻辑

```text
抓公开页 → 正文提取 → 1000 字分块
→ summarize_chapter → book_memory / reading_queue
→ 下次从 offset 续读
```

新增 source adapter：

```text
weibo   公开微博正文/长文
tieba   贴吧主题帖 + 楼中楼（只读）
zhihu   知乎回答/文章（只读）
```

约束：

- 只读公开页，不发帖、不评论、不点赞。
- 需要 Cookie 的平台放 `.env`，不写日志。
- 一页一次，限速；失败换源。
- 复用 `book_queue` 的 offset/status，不另建一套进度。
- 摘要只入库；自动流程不主动发消息（v29.4）。

### v36.11 随机内容消费

空闲时从池子里随机选：

```text
本地读书
贴吧
B站
微博
知乎
```

规则：

- 权重可配，默认读书略高。
- 同一 source 连续两次不选；有冷却。
- 随机到 B站/贴吧/微博/知乎时，走同一套分块/摘要/入库。
- 失败/空内容 → 换下一个源，不刷屏。
- 只有用户命令才回摘要：

```text
!feed random
!feed tieba
!feed weibo
!feed zhihu
!feed bilibili
!book next
```

自动流程只入库，不主动发摘要。

- 每个生态独立开关，默认关闭。
- 写操作必须审批；失败回滚。
- 不把平台密钥写进日志。
