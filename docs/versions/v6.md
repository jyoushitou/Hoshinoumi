# v6 · 说话像人

> 前置：无 ｜ 预估 2 天 ｜ 不动数据库，独立部署

## 目标

去掉机器味：不秒回、不「格式话」、群里不刷屏。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U2 | A22 A23 A3-剩余 | few-shot 示例对话、反 AI 腔清单、元数据改 JSON 字段 |
| U1 | A1 A12 A19 A20 | 延迟回复、分条发送、沉默短回复、情绪化排版 |
| U16 | E29 | 群聊触发：@ / 关键词 / 概率 + 60 秒冷却 |

## 涉及文件

`ai/persona.py`（反 AI 腔、示例对话）、`ai/prompt.py`、`chat/reply.py`（组装）、
`chat/send.py`（延迟、分条）、`chat/handler.py`（群聊冷却）、`core/state.py`

## 实施步骤

1. A23 反 AI 腔清单写进 prompt（禁排比三连/名词化/总结句/共情套话）
2. A22 从历史对话里挑 3~5 条做 few-shot
3. A1 延迟：`3s ~ 3min`，按时段与随机；`!` 命令立即
4. A12 分条：对话按句拆 2~3 个气泡，间隔 1~3 秒
5. A19 沉默：低概率只回「嗯」「……」
6. A20 排版：随状态改标点（先随机，v9 接 mood）
7. E29 群聊冷却（必须在 A12 之后，否则刷屏）
8. A3 剩余：元数据改 JSON 字段（可选，放最后）

## 验收

- [ ] 回复不再是 1 秒必到
- [ ] 一句话拆成 2~3 个气泡
- [ ] 连续 10 条无「不是…而是…」「总而言之」「我理解你的感受」
- [ ] 群里不再每句都接

## 风险

分条 + 延迟会让群里节奏变慢，E29 必须同版本做。
