# v35.9.35.4 群管理/撤回验收

日期：2026-11-26

## 管理员

```text
GET/POST /api/groups/{id}/admins
owner 可添加/移除管理员
```

## 自定义撤回提示

```text
PATCH /api/groups/{id}/settings
{"recall_notice":"管理员撤回了一条消息"}
```

## 管理员撤回任意消息

```text
POST /api/messages/{id}/recall
owner/admin -> 不受 2 分钟和“只能撤回自己”限制
meta.recall_notice / meta.recalled_by 写入历史
```

实测：

```text
撤回 assistant 消息 -> 200
history recalled=true
recall_notice=管理员撤回了一条消息
recalled_by=admin
```

测试消息与群设置已清理。
