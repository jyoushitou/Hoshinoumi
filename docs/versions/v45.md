# v45 系列 · 学习规划 / 计划表

> 位置：v44 接口层之后、原 v45 多端推送之前。  
> 新增 v45 后，原 v45–v67 顺延为 **v46–v68**。  
> 目标：把“本周计划表”做成一等能力，而不是塞几十条 `!cron`。

## 目标

```text
一张周计划表：7 天 × 若干格
每格是任务，不是课程表
任务可标记：待做 / 完成 / 跳过 / 顺延
按周生效，支持临时改计划
到点提醒，但不刷屏
```

## 它不是什么

```text
不是课程表：没有老师、教室、课程表学期结构
不是番茄钟：不强制计时
不是通用待办：围绕“这一周的学习计划”组织
```

格子里的内容可以是：

```text
课:Web实验（核验Web七八）
实:Java四
Linux资料·重定向
库中级一 视图
概率第1章
活动
```

## 数据模型

```text
study_plans
  id, user_id, week_start, title, status, created_at

study_slots
  id, plan_id, slot_no, start_time, end_time
  # 第1格..第10格，具体时间用户可配

study_items
  id, plan_id, day, slot_no, subject, task, kind,
      priority, estimate_min, actual_min, status, note, sort
  # status: todo / done / skipped / moved

study_item_events
  id, item_id, action, from_day, from_slot, to_day, to_slot,
      note, created_at
  # 审计：完成/跳过/顺延/改计划
```

约束：

```text
day: 1..7（周一到周日）
slot_no: 1..10
同一 plan + day + slot 可有多条任务，但 UI 按 sort 排
空/— 不建行
```

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v45.0** | 规划表 schema + 周/格/任务模型 + JSON 导入 | 旧库幂等；空表不报错 |
| **v45.1** | `!plan import/list/today/week` | 导入截图这种周计划，7 天可读 |
| **v45.2** | 完成/跳过/顺延 + 到点提醒 + 去重 | 任务状态可改；每格只提醒一次 |
| **v45.3** | 临时事务/顺延到第 10 格/周复盘/观测 | 不改模板；周结束自动归档 |

## 命令

```text
!plan                       本周概览
!plan today                 今天
!plan week 2026-11-16       指定周
!plan import <json>         导入周计划
!plan add <day> <格> <内容>
!plan done <id>             完成
!plan skip <id>             跳过
!plan move <id> <day> <格>  顺延/改期
!plan export                导出
```

全部仅主人可用。

## 执行规则

```text
到格子的开始时间
→ 查今天该格未完成任务
→ 发送一次提醒
→ 同一天同一任务不重复
```

- 默认提前 10 分钟。
- 空/已完成/已跳过不发。
- 考试/DDL 可以单独设更长提前量。
- 计划提醒和 `cron_tasks` 分开，不混列表。

## 顺延规则

截图里的备注：

```text
临时事务用当周第 10 格消化
```

v45.2 支持：

```text
任务错过 → 可手动 move 到本周末尾空闲格
不改原计划模板
顺延写 study_item_events
```

不自动把所有未完成任务堆到第二天，避免列表越滚越大。

## 第 12 周示例

```text
week_start=2026-11-16
slots=08:00,09:00,10:00,11:00,13:30,14:30,15:30,16:30,18:30,19:30
mon 3=课:Web实验（核验Web七八）
tue 2=Linux资料·重定向
wed 3=课:概率
thu 3=Linux随堂考
sat 3=库中级二 TSQ; 流程控制
sun 1=库中级二 收尾
```

具体时间由用户配置，不写死在代码里。

## 验收

```text
1. 导入第 12 周计划，!plan week 能看到 7 天
2. 空/— 不显示、不提醒
3. 到点只提醒一次
4. !plan done / skip / move 能改状态
5. 临时调课只影响当天，不改模板
6. 第 12 周结束后不再提醒
7. !cron 列表不增加几十条
```

## 非目标

- 不做教务系统登录。
- 不做课程表 OCR（后续可加）。
- 不强制番茄钟计时。
- 不替代 `!cron`；考试/DDL 仍可同时用 cron。
- 不做多人共享计划；先单主人。
