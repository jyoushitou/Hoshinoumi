# v16 · 她会在空闲时读小说

> 前置：v9（她有自己的生活）+ v12（共同的东西）+ v13（主动）｜预估 4 天

## 目标

**主人不找她的时候，她自己去看书**，看完记进度、有想法，之后聊天时能接上剧情。

不是「等她被问才说」，而是「她真的在过自己的时间」。

## 触发时机（关键）

读小说是**空闲行为**，不是定时行为：

| 条件 | 说明 |
|---|---|
| 主人多久没说话 | ≥ 2 小时（可调 `NAO_READ_IDLE_HOURS`） |
| 她现在闲着 | `energy` 不太低、没有正在进行的对话 |
| 今天读得不多 | 每天最多 20 章 / 3 次 |
| 不在深夜 | 01:00~07:00 不读书（她也在睡觉） |

和主动消息共用闸门，但**独立计数**——读书不该抢占「主动聊天」的配额。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U26 | E6 | 番茄 / 起点：拉免费章节，读 + 记进度 |
| U27 | E7 | 聊小说：记得看到哪、喜欢谁、不剧透 |
| U28 | E8 | 主动分享：读到有意思的地方会跟主人提一句 |

## 抓取方案：无头浏览器（已定）

实测结论：

| 平台 | 纯 HTTP 抓取 | 原因 |
|---|---|---|
| 番茄 | 目录/简介可用，**正文被字体加密**（部分字替换成私有区字符） | 站点反爬 |
| 起点 | **HTTP 202 + 空响应** | 需要执行 JS 挑战 |

所以采用 **Playwright + Chromium**，在真实浏览器环境里取渲染后的文本。

### 依赖与安装

```bash
pip install playwright
playwright install chromium          # 约 300 MB
playwright install-deps chromium     # 服务器缺系统库时
```

### 运行方式

- 浏览器**按需启动**，读完立刻关，不常驻
- 单次超时 30 秒，失败即放弃，不重试
- 并发上限 1（同一时间只开一个浏览器）
- 抓取在**线程里跑**（Playwright 同步 API 会阻塞事件循环）

### 成本

| 项 | 值 |
|---|---|
| 首次安装 | ~300 MB |
| 每次抓取 | 3~8 秒，内存峰值 ~200 MB |
| 每天次数 | ≤3 次，每次 1~3 章 |

### 失效处理

| 情况 | 处理 |
|---|---|
| Playwright 未安装 | 自动降级为「浅层在读」（书名/目录/进度） |
| 页面结构变了 | 解析失败 → 记日志 → 当天不再试 |
| 出现验证码 | 直接放弃，不绕过 |
| 抓取超时 | 放弃本次，不影响聊天 |
## 平台与可行性

| 平台 | 能读 | 难点 | 建议 |
|---|---|---|---|
| 番茄小说 | 免费书全本（**用 Playwright 取渲染文本**） | 反爬、结构变动 | ✅ 先做 |
| 起点 | 免费章节、试读（**需要无头浏览器过 JS 挑战**） | 202 空响应、付费章节读不到 | 后做 |

## 读什么、怎么读

```
空闲触发 → 挑一本在追的书 → 拉下一章正文（临时）
        → 生成摘要（≤100字）+ 记进度
        → 正文丢弃，只留摘要
```

**全文只在内存里过一遍，不落库、不进 prompt。**

## 记忆怎么存

```
events(kind='reading'):
  书名 | 平台 | 作者 | 已读章数 | 最近一章摘要(≤100字) | 喜欢的角色
```

每读 3~5 章更新一次摘要；同一本书一人一行。

## 聊小说（E7）

| 场景 | 她的反应 |
|---|---|
| 主人问「你在看什么」 | 说书名 + 一句现在的剧情 |
| 主人看过同一本 | 能聊角色，**先问看到第几章** |
| 主人没看过 | 只讲个开头，不剧透转折 |
| 台词引用 | 最多一句，标明是书里的 |

**剧透保护**：主人没读到的部分，她只能说「后面有转折」这种。

## 主动分享（E8）

读到有意思的地方，**可能**说一句——不是每章都报备。

| 闸门 | 值 |
|---|---|
| 概率 | 20%（读完一章后） |
| 冷却 | 3 小时 |
| 深夜 | 不说 |
| 正在聊天 | 不打断 |

## 验收

- [ ] 挂机两小时后，日志出现「读书」记录
- [ ] 问「你在看什么」能说出书名和剧情
- [ ] 记得看到第几章，不会重复读同一章
- [ ] 主人没读到的部分不会剧透
- [ ] 平台挂了不影响正常聊天

## 红线

| 红线 | 原因 |
|---|---|
| 不存全文 | 版权 + 库会爆 |
| 不碰付费/VIP 章节 | 不绕过付费墙 |
| 不转载章节内容 | 最多引用一句 |
| 每天 ≤20 章 | 别把账号刷成机器人 |
| 深夜不读 | 她也要睡觉 |

## 降级策略

| 失败 | 处理 |
|---|---|
| 章节拉取失败 | 换一本/跳过，不重试轰炸 |
| 平台要求登录 | 停止该平台，日志告警 |
| 摘要生成失败 | 存「读了第 N 章」，不写内容 |
| 当天已读满 | 不再读 |
