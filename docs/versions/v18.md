# v18 系列 · 她会发 QQ 空间

> 前面十几版，她只在你面前说话。这一版让她有个「对外的地方」。
> 状态：📋 规划中（v17 完成后开工）

## 为什么放在 v18

| 理由 | 说明 |
|---|---|
| 依赖出站层 | 发说说要复用 v17.2 的出站口（锁、重试、审计） |
| 依赖事件层 | 「她今天心情好」→ 投递一条 `qzone_post` 事件，而不是主循环里判断 |
| 比视频简单 | 发一条说说 = 一次 HTTP 请求；刷视频要抓取 + 理解 + 摘要 |
| 风险可控 | 只发文字/图，不点赞不评论不转发别人 |

## 前提：先确认可行性（第 1 天）

发说说不是官方 API，走的是 QQ 空间的网页接口，需要登录态 cookie。

| 方案 | 做法 | 风险 |
|---|---|---|
| **A. Qzone 网页接口**（主选） | 用 `uin` + `skey` + `p_skey` 调 `emotion` 发布接口 | cookie 会过期；频繁发会被风控 |
| B. NapCat 插件 | 看 NapCat 是否提供 qzone 相关 action | 取决于版本，可能没有 |
| C. 不自动发，只提醒 | 生成文案发到私聊，主人自己复制去发 | 最安全，但不算「她自己发」 |

**第 1 天先做 A 的可行性验证**：

1. 用真实 cookie 手动调一次发布接口，确认能发出去
2. 确认失败时的返回（cookie 过期 / 风控 / 内容审核）
3. 拿不到可用 cookie 就退到 C，v18 缩水为「生成文案 + 提醒」

**cookie 放哪**：`config.local.json` 的 `qzone` 段（不进版本库），
或 `data/qzone.json`（已 gitignore）。

## 她发什么

| 类型 | 触发 | 例子 |
|---|---|---|
| **日常** | 每天最多 1 条，随机时刻 | 「今天下雨，懒得动」 |
| **读书感想** | 读完一章且摘要够好 | 「这章看得我有点难受」 |
| **心情** | 心情值越过阈值（很高/很低） | 「烦」 |
| **节日/生日** | 固定日期 | 「又老一岁」 |

**不发什么**：

- 不发明明是「对主人说」的话（那是私聊的事）
- 不发链接、不发广告、不发政治内容
- 不 @ 任何人、不评论别人、不点赞

## 频率与安全

| 规则 | 值 | 理由 |
|---|---|---|
| 每天上限 | **1 条** | 多了像营销号 |
| 最小间隔 | 6 小时 | 防连发 |
| 深夜不发 | 0:00–8:00 | 没人看，也容易被判定异常 |
| 失败重试 | **0 次** | 发说说失败就放弃，重试更容易触发风控 |
| 连续失败 | 3 次 → 停 7 天 | 自动降级，别硬撞 |
| 内容长度 | ≤ 200 字 | 说说太长会被折叠 |

**红线**：这一版**只发自己的说说**，绝不点赞、评论、加好友、看别人的空间。

## 实现

```
botv/qzone/
├── client.py     发布接口（cookie 注入、超时、错误分类）
├── compose.py    文案生成（复用她的人设 + 当天状态）
└── policy.py     频率闸门（每天 1 条、6 小时间隔、深夜不发）
```

事件：

```python
@register("qzone_tick", priority=Priority.EVENT, timeout=30)
async def handle_qzone_tick(ev):
    ok, why = policy.should_post()
    if not ok:
        return {"ok": False, "reason": why}
    get_scheduler().submit("qzone_post", "qzone:post", args=(...))

@register("qzone_post", priority=Priority.EVENT, timeout=60, retries=0)
async def handle_qzone_post(ev):
    text = await compose.daily_text()
    ok, detail = await client.publish(text)
    ...
```

## 配置

```json
{
  "qzone": {
    "enabled": false,
    "cookies": {"uin": "", "skey": "", "p_skey": ""},
    "daily_limit": 1,
    "min_interval_hours": 6,
    "quiet_hours": [0, 8]
  }
}
```

`enabled` 默认 **false**——不填 cookie 就不发，避免一升级就出问题。

## 命令

| 命令 | 作用 |
|---|---|
| `!qzone` | 看今天发了没、下次能发的时间 |
| `!qzone test` | 立刻生成一条（**不发**，只给她看） |
| `!qzone post` | 立刻发一条（二次确认） |

## 验收

| 项 | 标准 |
|---|---|
| 不配置时 | 完全不发，日志一行「未启用」 |
| 配置后 | 每天最多 1 条，间隔 ≥ 6 小时 |
| 失败 | 不重试，记一条日志，不影响聊天 |
| 内容 | 不含链接、不含 @、≤200 字 |
| 连败 | 3 次后自动停 7 天 |

## 风险

| 风险 | 应对 |
|---|---|
| cookie 过期 | 失败即停，日志提示「重新获取 cookie」 |
| 被风控 | 每天 1 条 + 深夜不发 + 失败不重试 |
| 内容审核 | 不发敏感词；生成后过一遍过滤 |
| 账号安全 | cookie 只存在本地文件，不进版本库、不写日志 |
