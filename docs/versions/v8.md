# v8 · 想得起来

> 前置：v7 ｜ 预估 4 天 ｜ 检索变强，同时拆锁

## 目标

问「我上周说啥」答得对；两个人同时聊不排队。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U5 | B11 B12 B13 B16 B17 | 相关度检索、关键词分对象、分层注入（1800 token）、时间线注入、双路召回 |
| U15 | E26 E27 E28 | 分片锁、HTTP 会话复用、超时分级 |

## 涉及文件

`memory/recall.py`（新建）、`memory/inject.py`（新建）、`ai/prompt.py`、
`ai/client.py`、`chat/handler.py`、`core/state.py`

## 实施步骤

1. 本地 embedding（bge-small）接入，bootstrap 预热
2. 双路召回：关键词 LIKE + 向量余弦，RRF 融合取 top5
3. 分层注入：人设 / 画像 / 近对话 / 检索，总预算 1800 token
4. 时间线注入：最近 7 天事件按时间序
5. 关键词分对象（拆掉全库共享的 40 个）
6. E26 分片锁：`dict[target_id, Lock]` + 空闲清理
7. E27/E28：会话单例、超时分级

## 验收

- [ ] 问「我上周说啥」能答对
- [ ] 两个人同时聊不排队
- [ ] prompt 总长稳定在预算内

## 风险

embedding 首次加载 1~2 秒；检索失败要降级为纯关键词，不能让回复挂掉。
