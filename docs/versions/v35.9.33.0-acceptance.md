# v35.9.33.0 聊天模式 API 验收

日期：2026-11-26

## 接口

```text
GET  /api/chat/mode
POST /api/chat/mode          {"mode":"chat|code|agent|shell"}
POST /api/chat/mode/approve  {"command":"","approved":true|false}
```

## 状态

```text
mode / label / modes
updated_at / expires_at / expires_in
agent_task
approval
```

## 规则

```text
owner-only
四选一，互斥
Code 30 分钟超时，GET 时自动回 Chat
Shell 审批只在 Shell 模式有效
状态持久化 data/chat_mode.json
```

实测：

```text
GET -> Chat
POST code -> expires_in 1800
POST shell -> shell
approve -> 记录命令与拒绝状态
POST chat -> 恢复 Chat
```
