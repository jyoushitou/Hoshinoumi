# v35.9.26.1–.3 本地书阅读验收

日期：2026-11-26

## 后端

```text
GET  /api/books
GET  /api/books/{id}
GET  /api/books/{id}/content?chapter=
GET  /api/books/{id}/progress
PUT  /api/books/{id}/progress
POST /api/books/refresh
```

存储：

```text
data/books/*.txt
data/books/*.epub
book_reading_progress(user_id, book_id, chapter, percent)
```

规则：

```text
只读 data/books
TXT：UTF-8/GB18030/BIG5，按“第 N 章 / Chapter / 序章”切章
EPUB：container.xml -> OPF spine -> 正文纯文本
路径穿越 / 软链接逃逸拒绝
空书架返回 []，不伪造
```

## 前端

```text
/books        书架：继续阅读、格式、大小、进度、空态
/books/:id    阅读器：目录、上一章/下一章、字号、行距、主题、进度保存
```

实测：

```text
TXT 三章 -> 目录 3
EPUB 两章 -> 目录 2
PUT progress -> 200
GET progress -> chapter/percent
书架卡片 2 -> 点击进入阅读器
```

测试样书已删除；`data/books/` 放真实书后点「重新扫描」。
