# v25 系列 · 模型层接口

> 核心：只定义第三方模型实现接入的接口。
> DeepSeek / 豆包仍是核心 native 实现，不注册为插件。

```python
class ModelRequest(Protocol):
    messages: list[dict]
    temperature: float
    max_tokens: int
    user_id: str


class ModelReply(Protocol):
    text: str
    usage: dict
    provider: str


class ModelProvider(Protocol):
    name: str
    def capabilities(self) -> set[str]: ...
    async def complete(self, req: ModelRequest) -> ModelReply: ...
```

规则：

- 核心 provider 不实现 `PluginManifest`，不进入插件表。
- 第三方 provider 通过 `PluginRegistry` 注册，只作为可选路径。
- 核心 provider 只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
