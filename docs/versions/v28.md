# v28 系列 · 工具层接口实现

> 核心：把现有工具包成 `Tool` 实现，并暴露第三方工具接口。
> 现有工具是核心 native，不注册为插件。

```python
class Tool(Protocol):
    name: str
    schema: dict
    permissions: set[str]
    async def invoke(self, user_id: str, args: dict) -> dict: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v28.0** | `ToolSpec` / `Tool` 契约 | 业务只依赖接口 |
| **v28.1** | 现有工具 native adapter，逐个包 | 工具行为不变 |
| **v28.2** | 权限/超时统一入口 | 越权/超时被拒绝 |
| **v28.3** | 第三方工具 adapter + fake 测试 | 新工具不改业务 |

## 关键约束

- 现有工具是核心 native，不注册为插件。
- 第三方工具必须有 schema/权限；失败由 v32 回退核心工具。
- 核心工具只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
