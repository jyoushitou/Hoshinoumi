# v28 系列 · 插件运行时（审批 / 加载 / 错误 / DDL）

> 前置：v27 注册表基础。  
> 本层只做插件运行时，不实现具体 provider / channel / tool / storage。  
> 具体能力层从 **v29 模型层** 开始，每层两版：契约 + native、插件接入。

完整跨版本总纲：[INTERFACE-PLAN-v27-v44.md](../INTERFACE-PLAN-v27-v44.md)。

## 目标

```text
manifest-first 加载
权限三档 + 安装审核 + 命令修改
plugin_errors + 连续失败自动停用
任务 / 线程池 / DB 连接池统一 context
插件 DDL 独立迁移

```

## 插件目录

```text
plugins/
  models/
  channels/
  memory/
  tools/
  storage/
    <plugin>/
      plugin.json
      plugin.py
      migrations/
        001_init.sql
```

`prepare_worker` 把启用插件快照进：

```text
data/workers/versions/<version>/plugins/
```

worker 启动时只读本版本快照，旧 worker 不读新插件文件。

## 权限与审批

权限点：

```text
config.read
config.secret
db.read
db.write
file.read
file.write
network.outbound
event.read
event.emit
plugin.call
```

三档：

```text
0 = 拒绝
1 = 调用时询问主账号
2 = 直接允许
默认 = 1
```

流程：

```text
安装插件
→ 主账号审核（询问所有权限点）
→ 写 plugin_permissions
→ 后续 !plugin permission <name> <permission> <0|1|2>
```

表：

```text
plugin_approvals
  id, plugin, action, resource, status,
  requested_at, approved_by, approved_at, expires_at, note

plugin_permissions
  plugin, permission, scope, level, approved_by, updated_at
```

## 错误与自动停用

```text
plugin_errors
  plugin, version, capability, phase, error, traceback, created_at
```

规则：

```text
插件注册失败不阻塞核心启动
连续失败达到阈值自动停用
!plugin errors 可查
!plugin disable / enable 可手动恢复
traceback 脱敏，不写 token/cookie
```

## 任务 / 线程 / 连接池

插件工厂收到 `ctx`：

```python
ctx.tasks.spawn(name, coro, owner="plugin:...")
await ctx.pool.run_blocking(fn, timeout=...)
with ctx.db.cursor() as c: ...
```

- `TaskManager` 持有任务，worker 关闭时统一 cancel。
- 线程池复用 `infra/blocking`。
- DB 连接池统一到 `infra/pool`；插件禁止直接 `infra.conn`。

## DDL

```text
plugins/<layer>/<name>/migrations/001_init.sql
```

规则：

```text
只支持 MySQL + SQLite
表前缀 plugin_<name>_
不允许改核心表
启动不建表
!plugin migrate <name> 先 dry-run，主账号确认后执行
记录 plugin_schema_version
```

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v28.0** | 权限三档 + 审批表 + `!plugin permission` | 默认 ask；0/1/2 可改 |
| **v28.1** | manifest-first loader + 热更快照 + 自动加载已启用插件 | 坏插件不影响核心；旧 worker 不读新文件 |
| **v28.2** | `plugin_errors` + 连续失败自动停用 + `!plugin errors` | 故障可查；自动停用生效 |
| **v28.3** | TaskManager + 共享线程池/DB pool context | 插件不裸 create_task / 裸连库 |
| **v28.4** | `migrations/` + `!plugin migrate` dry-run + 文档 | 只建插件表；批准后执行 |
