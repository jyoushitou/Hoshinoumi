# v28 系列 · 插件运行时（Context / 审批 / 加载 / 错误）

> 前置：v27 注册表基础。  
> 运行时契约先定：[PLUGIN-RUNTIME-DESIGN.md](../PLUGIN-RUNTIME-DESIGN.md)。  
> v28 只做运行时，不做具体能力；插件 DDL 下沉到 **v38 存储层**。

## 目标

```text
核心 DB pool 统一
schema 30 + plugin_* 核心表先建
PluginContext 完整接口
安装/审批/权限三档
manifest-first loader + plugin-lock generation
错误降级/停用 + 启动自启
插件 stop 跟随 worker
```

## 迁移顺序（修正）

```text
v28.0  核心 repo_* 切 infra/pool
v28.1  schema 29 → 30，建 plugin_registry / approvals / permissions / errors
v28.2  PluginContext + TaskManager + 权限执行
v28.3  安装 / loader / plugin-lock / generation 校验
v28.4  审批命令 + 错误降级/停用 + 启动自启

```

## 核心 registry 表

```text
plugin_registry        插件安装/启用/auto_start/hash/author/layer
plugin_approvals       安装/权限审批
plugin_permissions     权限三档 + scope
plugin_errors          错误记录
plugin_schema_version  插件迁移版本（v38 使用）
plugin_registry_generation 当前 generation
```

迁移：

```text
schema_version 29 → 30
scripts/migrate_v28.py
```

## 安装与 hash

```text
!plugin install <package>
→ manifest: name/author/layer/version/api_version/capabilities
→ 计算包 hash
→ 复制到 plugins/<layer>/<name>/
→ 同名 hash 相同：重复安装；hash 不同：拒绝
→ 进入 pending
```

不信任包名，以 manifest name + hash 为准；layer 只能是
`models/channels/memory/tools/storage`。

## 权限

```text
0 拒绝 / 1 调用时询问 / 2 直接允许，默认 1
scope: config:key / db:table / file:glob / network:host / event:kind / plugin:capability
```

任何越权表、越界路径、未授权 host 直接抛 `PermissionDenied`，不执行副作用。

## PluginContext

完整接口见 [PLUGIN-RUNTIME-DESIGN.md](../PLUGIN-RUNTIME-DESIGN.md)：

```text
ctx.manifest / registry / config / db / files / network / events
ctx.ai / memory / storage / tasks / pool / logger / permissions / lifecycle
ctx.on_stop(fn)
```

插件禁止裸 `create_task`、裸连 DB、裸 requests。

## 生命周期

```text
worker SIGTERM / drain
插件 disable / 自动 disabled
版本升级旧 worker 退出

→ 停止接新调用
→ cancel owner tasks
→ plugin.stop(ctx)，最多 5s
→ 关闭游标/连接
→ registry.unregister
→ generation +1
```

不跟随 ingress；运行中 disable 立即 stop，下一次 worker 不再加载。
自动停用不自动恢复；`auto_start=true` 且 enabled 的插件在 worker 启动时加载。

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v28.0** | 核心 repo_* 统一切 `infra/pool`；conn 仅兼容 | MySQL/SQLite 现有行为不变 |
| **v28.1** | schema 30 + plugin_* 核心表 + `_check_schema` 更新 | 旧库迁移幂等；启动校验 30 |
| **v28.2** | PluginContext + TaskManager + 权限执行 | 越权表/路径直接拒绝 |
| **v28.3** | install + manifest loader + plugin-lock generation + 启动校验 | generation 不一致拒绝加载 |
| **v28.4** | pending/approve/reject/permission 命令 + 错误降级/停用 + auto_start | 默认 ask；停用不自动恢复 |
| **v28.5** | stop 生命周期 + `!plugin list/errors` + 回归 | list 不显示核心；stop 跟随 worker |

## DDL

**不在 v28 做。** 插件 `migrations/` 由 v38 存储层提供：

```text
v38：MySQL/SQLite 方言、dry-run、事务、plugin_schema_version
```

v28 只记录插件 schema_version，不执行建表。

## 卸载

插件开发者提供 `uninstall(ctx)` 清理自己的数据；核心不自动 drop 表，只移除插件文件和注册表记录。

## 非目标

- 不实现模型/记忆/通道/工具/存储能力（v29+）
- 不让插件注册新注册表
- 不运行中 `importlib.reload`
- 不自动 drop 插件表
