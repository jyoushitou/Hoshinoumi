# v28 系列 · 工具层接口

> 核心：只定义第三方工具实现接入的接口。
> 现有工具是核心 native 实现，不是插件。

```python
class ToolSpec(Protocol):
    name: str
    description: str
    schema: dict
    permissions: set[str]


class Tool(Protocol):
    spec: ToolSpec
    async def invoke(self, user_id: str, args: dict) -> dict: ...
```

规则：

- 核心工具不注册到插件表；插件只能新增工具或包装权限/审计。
- 插件工具异常/超时由调用方回退核心工具。
- 核心工具只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
