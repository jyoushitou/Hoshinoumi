# v35.9.28.0–.3 文件库验收

日期：2026-11-26

## 接口

```text
GET    /api/files
POST   /api/files/init
GET    /api/files/{id}/upload
PUT    /api/files/{id}/chunk
POST   /api/files/{id}/complete
GET    /api/files/{id}/download?offset=&length=
DELETE /api/files/{id}
POST   /api/files/{id}/share
GET    /api/files/share/{token}
GET    /api/files/share/{token}/download
```

## 规则

```text
单文件 ≤ 30 MB；分片 ≤ 4 MB；账号配额 2 GB
文件名清洗；只存 data/files/<id>，不暴露真实路径
分片 offset 可续传；complete 校验大小并写 sha256
分享只读、可过期、可限下载次数
分享页不需要登录
```

## 实测

```text
-> chunk 剩余 -> complete 200
download 分片 -> 1900 bytes
share -> public info 200
share download -> 200
delete -> 200
```
