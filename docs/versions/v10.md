# v10 · 关系与主动

> 前置：v9 ｜ 预估 4 天

## 目标

从「你问她答」变成「她会想起你」。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U8 | C18 C19 C20 | 关系分档、边界（会拒绝）、不完美（会记错） |
| U9 | D22 D25 | 想念驱动主动消息、沉默权（刚聊过/深夜不发） |
| U9b | D26 D27 D28 D29 | 主动的四种新由头：分享生活 / 回访承诺 / 状态外溢 / 时间锚点 |
| U10 | D23 F36 | 日程提醒 + `!todo` 命令 |

## 涉及文件

`ai/prompt.py`、`chat/handler.py`、`schedule/runner.py`、
`life/agenda.py`（新建）、`life/impulse.py`（新建，U9b）、`cmd/admin.py`（新增 todo 命令）

## 实施步骤

1. 亲密度分四档 → 称呼与语气
2. 边界：群里不 @ 不接；忙时回「等下」
3. 不完美：允许「记不太清了」
4. 主动消息改成 loneliness 驱动（替代定点模板）
5. 沉默权：刚聊过 / 深夜 / 连续无回应 → 不发
6. 日程抽取（「周五面试」→ agenda）与到期提醒
7. `!todo` 命令
8. **U9b-1 分享生活**：取当天生成的生活事件，挑一条主动说（受 D25 沉默权和每日上限约束）
9. **U9b-2 回访承诺**：检测「回头再说 / 晚点聊 / 改天」→ 记一条待办，次日主动问
10. **U9b-3 状态外溢**：`mood < -0.5` 且独处超过 X 小时 → 发一条更短、更别扭的（「在吗」）
11. **U9b-4 时间锚点**：检测「去吃饭 / 洗澡 / 开会 / 睡一会」→ 20~40 分钟后问一句「完了？」

## 验收

- [ ] loneliness 高才主动发
- [ ] 说「周五面试」→ 周四晚上她提
- [ ] 群里不 @ 不接话
- [ ] 她说出当天的生活事件（不是模板化的「今天过得怎么样」）
- [ ] 说「先不聊了，回头说」→ 隔天她主动问
- [ ] 说「我去吃饭」→ 半小时后她问「吃完没」
- [ ] 主动消息每天 ≤3 条（U9b 的所有由头共享这一个上限）

## 风险

主动消息过密会烦人，需要硬上限（每天 ≤3 条）。
U9b 的四种由头**必须共用同一个配额**，否则叠加起来一天能发七八条。
