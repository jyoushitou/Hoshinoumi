# v38 系列 · 存储层插件接入

> 前置：v37 存储层契约 + native adapter。  
> 本版只做第三方 存储层实现接入，不重写核心 native。  
> 跨版本总纲：[INTERFACE-PLAN-v27-v44.md](../INTERFACE-PLAN-v27-v44.md)。

## 目标

```text
PluginRegistry 注册 存储 adapter
→ 权限 / 错误 / 任务 / 热更走 v28 运行时
→ 调用方 get() 拿不到时回落 MySQL / SQLite
```

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v38.0** | 第三方 `StorageBackend / Repository` adapter 接入点 + fake 实现 | 不改业务代码即可切换实现 |
| **v38.1** | 权限、错误、任务、热更接入 | 违规调用被拒绝；失败可查 |
| **v38.2** | 回归、文档、停用/回滚 | native 默认不受影响 |

## 能力与约束

- 能力名：`storage.backend.<name>@1 / storage.repository.<name>@1`。
- 核心 native（MySQL / SQLite）不实现 PluginManifest、不进入插件表。
- 默认仍走 native；插件只能作为候选，除非显式路由/配置切换。
- 插件实现 `StorageBackend / Repository`，通过 v27 `PluginRegistry` 注册。
- 插件任务、线程池、DB 连接池由 v28 context 提供。
- 插件失败写 `plugin_errors`，连续失败自动停用。
- 插件 DDL 只允许 `plugin_<name>_` 前缀，MySQL/SQLite。

## 非目标

- 不重新定义 存储层 Protocol（v37 已完成）
- 不把 native 插件化
- 不允许插件改核心默认实现
