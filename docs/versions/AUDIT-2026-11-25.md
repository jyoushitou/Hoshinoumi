# v35 功能真实状态审计

日期：2026-11-25  
范围：v35.9.4.x – v35.9.34.x

## 结论先说

```text
设计稿 ≠ Mock 可用 ≠ 真实网关可用 ≠ 真实后端可用 ≠ Vue 可用
```

当前大量功能只在 **Mock 网关 + Vue** 下通过，生产链路仍有缺口。最关键的缺口是：

```text
gateway/src/router.cpp 只对少量 POST 做了专门转发：
  /api/chat
  /api/topic
  /api/messages/*/recall
  /api/read
  /api/cron（本次新增）
  /api/login、/api/register、/api/refresh

其余 /api/* 的 POST / PATCH / DELETE 没有通用写转发。
```

结果：

```text
GET  /api/persona        真实网关可用
POST /api/persona/import 真实网关 404 / method_not_allowed
POST /api/savings/entries 真实网关不可用
POST /api/weekly-plan    真实网关不可用
POST /api/command        真实网关不可用
POST /api/plugins/*      真实网关不可用
```

Mock 网关支持这些写操作，所以前端联调看起来是通的，但不能算生产完成。
