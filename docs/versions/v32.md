# v32 系列 · 默认链路选择实现

> 核心：实现 `RouteRegistry` / `FallbackChain`，把默认架构的执行链路
> 从“业务直接调用实现”改为“先选默认实现，再调用”。
>
> **默认永远选核心 native**；第三方插件只能注册候选，不能改变默认核心。

## 默认链路

| 层 | 默认 native | 改动前 | 改动后 |
|---|---|---|---|
| 模型 | DeepSeek（失败豆包 native） | 业务直接调 client | RouteRegistry -> native |
| 记忆 | BM25 | 直接调 retrieval | RouteRegistry -> native |
| 通道 | QQ / NapCat | 直接调 send | RouteRegistry -> native |
| 工具 | 现有工具 | 直接调函数 | RouteRegistry -> native |
| 存储 | MySQL/SQLite | 直接拼 SQL | RouteRegistry -> native |
| 调度 | asyncio | 直接 call_at | RouteRegistry -> native |
| 出站 | WebSocket | 直接 ws.send | RouteRegistry -> native |

## 接口

```python
class RouteKey(Protocol):
    layer: str
    capability: str
    user_id: str
    scene: str


class Candidate(Protocol):
    origin: str          # "native" | "plugin"
    name: str
    priority: int
    health: str


class RouteRegistry(Protocol):
    def resolve(self, key: RouteKey) -> list[Candidate]: ...


class FallbackChain(Protocol):
    async def call(self, key: RouteKey, fn) -> object: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v32.0** | `RouteKey` / `Candidate` / `RouteRegistry` 契约 + native 注册 | 每层都能解析到 native |
| **v32.1** | 默认链路切换：业务改走 registry，默认 native | 七层行为与 v31 一致 |
| **v32.2** | `FallbackChain`：失败/超时/空结果回退 native | 默认链路可回退 |
| **v32.3** | 第三方候选注册点 + 默认优先级低于 core | 插件不能抢默认 |
| **v32.4** | `!route` 只读视图 + 决策日志 + 七层回归 | 能解释为什么走 native |

## 默认规则

1. 没有插件时，`resolve()` 返回 `[core native]`。
2. 插件候选的 `priority` 不能超过核心默认优先级；默认路由永远选 native。
3. 只有显式配置把某层切换为插件候选，才可能先走插件；失败立即回退 native。
4. 核心 native 不出现在插件表，不走 manifest。
5. 核心只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。

## 验收

```bash
!route list                 # 七层默认 native
!route test model           # 命中 DeepSeek native
!route log                  # 候选链/命中/耗时
```

- 不装插件：七层行为与 v31 完全一致。
- 插件注册后：默认仍走 native。
- 插件显式启用后失败：回退 native。
- 核心 native 永远在候选链末尾。
