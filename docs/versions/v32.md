# v32 系列 · 跨层接口与回退契约

> 核心：只定义“第三方实现如何被选择、失败如何回到核心”的接口。
> 本版不实现任何插件。

```python
class RouteKey(Protocol):
    layer: str
    capability: str
    user_id: str
    scene: str


class Candidate(Protocol):
    origin: str          # "native" | "plugin"
    name: str
    priority: int
    health: str          # "ok" | "down" | "unknown"


class RouteRegistry(Protocol):
    def resolve(self, key: RouteKey) -> list[Candidate]: ...


class FallbackChain(Protocol):
    async def call(self, key: RouteKey, fn) -> object: ...
```

规则：

- `native` 是核心实现，永远在候选链末尾，不注册为插件。
- 插件只提供 `plugin` 候选；失败/超时/空结果由 `FallbackChain` 回退 `native`。
- 核心候选只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
