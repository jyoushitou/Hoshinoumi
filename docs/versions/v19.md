# v19 系列 · QQ 空间

> 前置：v17（出站层 + 调度）、v18（记忆分量）｜预估 5 天｜**三个次版本**
>
> 她发自己的说说——每天最多一条，**只发不互动**。

## 为什么做这个

微信/QQ 聊天是「一对一」；QQ 空间是**公开的表达**。
她在那儿不是回答你，而是**自己想说点什么**——这是「有生活」的最后一块。

## 第一步：可行性（1 天，可能直接砍掉）

QQ 空间没有公开 API。可能的路径：

| 方案 | 做法 | 风险 |
|---|---|---|
| **A. 带 cookie 的 HTTP 接口**（主选） | 用你登录后的 cookie 调 `qzone.qq.com` 的发说说接口 | cookie 会过期；接口可能改 |
| B. 浏览器自动化（退路） | Playwright 打开空间页面点「发表」 | 慢、重、易被风控 |
| C. 不做 | 只在聊天里说「今天想发个说说」 | 零风险，但没真的发 |

**第 1 天就验证 A**：能不能用 cookie 发一条纯文本说说。
拿不到就退 B，再不行就 C（这一版缩水成「她会在聊天里念叨想发什么」）。

## 红线（写死在代码里）

| 红线 | 原因 |
|---|---|
| **每天最多 1 条** | 刷屏会被举报 |
| **只发不互动**（不点赞、不评论、不访问别人空间） | 互动是最容易被判定为机器人的行为 |
| **默认关闭**（`enabled: false`） | 用户不主动开，就绝不发 |
| **内容过一遍自检**：不含隐私、不含真实地址、不含政治 | 公开内容，风险最高 |
| 不发自拍/不发自拍图（有图也只发 ACG 图） | 避免伪造真人形象 |

## 次版本拆分

| 版本 | 内容 | 天数 |
|---|---|---|
| v19.0 | 可行性验证：cookie 发一条纯文本 | 1 |

## v19.0 · 可行性验证（1 天）

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | `!qzone login <cookie>` 存 cookie（加密存 settings） | 能存能读 |
| U2 | `qzone_post(text)` 发一条纯文本 | 空间里真的出现 |
| U3 | 失败明确报错（不是静默） | 日志能看到原因 |

**验收**：手动发一条「测试」，空间里能看到。

## v19.1 · 内容生成（2 天）

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 素材来源：当天日记 + 重记忆（v18 的 weight ≥ 0.7） | 有候选清单 |
| U2 | 生成一条 ≤ 80 字的说说 | 不像 AI 写的 |
| U3 | 自检：隐私/地址/敏感词过滤 | 命中就不发 |
| U4 | `!qzone preview` 先看再发 | 能预览 |

**为什么要「值得说」**：不能每天「今天天气不错」——那是最像机器人的内容。

## v19.2 · 定时与降级（2 天）

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 每天固定时段（默认 20:00）挑概率发（30%） | 不是每天必发 |
| U2 | 发失败 → 退回聊天里说「我今天想发个说说，没发出去」 | 有反馈 |
| U3 | `!qzone on/off` 开关 | 默认关 |
| U4 | 记录：发了什么、什么时候（`qzone_log` 表） | 可回溯 |

## 验收（系列整体）

| 项 | 标准 |
|---|---|
| 能发 | 空间里出现一条 |
| 频率 | 一周不超过 7 条 |
| 内容 | 没有隐私/地址/敏感词 |
| 失败可见 | 发不出去会在聊天里说 |
| 默认关 | 不改配置不会自己发 |

## 风险与处理

| 风险 | 处理 |
|---|---|
| cookie 过期 | 报错提示重新登录；不重试 |
| 被风控/封号 | 每天 1 条上限 + 只发不互动；发现异常立刻停 |
| 内容不当 | 发布前自检；命中直接放弃（不发也不问） |
| 用户不想公开 | 默认关闭，`enabled: false` |
