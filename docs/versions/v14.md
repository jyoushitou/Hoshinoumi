# v14 · 打磨与余量

> 前置：v11（感官）｜ 预估 3 天
> 条目来源：[V14-后续清单.md](../V14-后续清单.md)（H/I/J 编号，接在 v6–v13 的 A~G 之后）

## 目标

不加大件，只把已经上线的**频率、阈值、边界**调顺。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U18 | H1 H3 | 发图与语音择时：不是每条都带图和语音 |
| U19 | H2 | 主动频率自适应：连续没回应就降频 |
| U20 | I1 I2 I3 | 解析与记忆精度收尾 |

## 实施步骤

1. **发图择时（H1）**
   - 只有 AI 明确给出图片关键词时才考虑配图
   - 每次 30% 概率配图，同一个人 10 分钟内最多一张
   - 群里连发时更保守（20%）
   - 心情差时几乎不配图（×0.5）
2. **语音择时（H3）**：与 H1 同一套概率闸门
3. **主动频率自适应（H2）**
   - 记录「主动后 30 分钟内是否收到回复」
   - 连续 3 次没回应 → 基础概率 ×0.5（下限 0.5）
   - 有回应 → 每次 +10% 回升，上限回到原值
4. **解析与记忆精度（I1 I2 I3）**
   - 日程支持「下个月」「月底」「这周末」
   - 记忆指代词只在检索为空时提示
   - CLIP 残留清理

## 验收

- [ ] 连续 10 条回复里，配图不超过 3 条
- [ ] 主动 3 次没被理，第 4 次概率明显下降
- [ ] 「月底交报告」能正确识别
- [ ] `grep -r "analyze_image_with_clip" botv/` 只剩 def

## 风险

发图概率调低之后，「她会发图」这件事的存在感会变弱——需要观察是不是低到看不见。
建议先设 30%，跑一周看实际配图率再定。
