# v35.9.35.0 会话偏好 API 验收

日期：2026-11-26

## 接口

```text
GET   /api/conversations/preferences
PATCH /api/conversations/{target}      muted / hidden
DELETE /api/conversations/{target}     删除/退群，body.dissolve
GET   /api/groups/{id}/admins
POST  /api/groups/{id}/admins          action add/remove
GET   /api/groups/{id}/settings
PATCH /api/groups/{id}/settings        recall_notice
```

## 表

```text
conversation_preferences
group_admin_roles
group_settings
```

## 实测

```text
PATCH muted -> 200
GET preferences -> muted=true
GET admins -> ["12345"]
GET/PATCH settings -> “群主撤回了消息”
DELETE conversation -> deleted=true
```

全部 owner-only，状态持久化 SQLite。
