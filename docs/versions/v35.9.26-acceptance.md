# v35.9.26.0 阅读 / 书架 API 验收

日期：2026-11-26

## 接口

```text
GET /api/shelf
```

返回：

```json
{
  "ok": true,
  "data": {
    "books": [],
    "book_count": 0,
    "active_book": null,
    "day": "",
    "chapters": 0,
    "daily_chapters": 20,
    "quota_left": 20
  }
}
```

## 规则

```text
owner 书架只返回真实阅读状态，不伪造书
books: title/url/last_no/last_title/intro
active_book: 最近在读；没有则为 null
day/chapters: 今日阅读统计
quota_left: 今日剩余章节配额
空书架返回 books=[]，由前端显示空态
```

## 验证

```text
请求 /api/shelf -> 200
空状态 book_count=0 / active_book=null / quota_left=20
```
