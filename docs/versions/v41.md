# v41 系列 · 嵌入式前端

> 大版本 v41。原 v40 嵌入式前端顺延到此。
> 目标：常亮屏显示对话，复用 Web UI 与 v35 hub/本机服务。

## 1. 范围

```text
树莓派/平板 + Chromium kiosk
触摸/软键盘/息屏唤醒
断网/重启恢复
```

不做：

```text
不写原生 App
不新起后端
不把嵌入式当第二套核心
```

## 2. 架构

```text
Chromium kiosk
  → http://127.0.0.1:5492（Web UI）
  → v35 hub / 本机服务
```

## 3. 次次版本

| 版本 | 内容 | 开发思路 | 验收 |
|---|---|---|---|
| **v41.0.0.0** | 嵌入式镜像/最小系统 | Pi OS Lite + Chromium kiosk + 自启 | 开机进聊天 |
| **v41.0.1.0** | 触摸/软键盘/息屏唤醒 | 触摸滚动；软键盘；DPMS | 可触摸输入 |
| **v41.0.2.0** | 断网/重启恢复 | 本地缓存最后会话；重连补拉 | 断网不白屏 |
| **v41.1.0.0** | 统计 + 修 v41 遗留 bug | 只修 bug；设备回归 | 测试全绿；P0/P1 清零 |

## 4. 思路

- 不写原生 App；Chromium kiosk 加载 Web UI。
- 断网显示最后缓存 + “重连中”，不假装在线。
- 触摸目标 ≥44px；软键盘不能遮输入框。

## 5. 验收

```text
1. 开机进入对话
2. 触摸/软键盘可用
3. 断网显示离线，不白屏
4. 重启恢复
```
