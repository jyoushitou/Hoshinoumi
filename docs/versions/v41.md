# v41 系列 · 出站层契约与 native adapter

> 核心：把 WebSocket 出站包成 `Transport` 实现，第三方 transport 接入在 v42。
> WebSocket 是核心 native，不注册为插件。

```python
class Transport(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def send(self, msg: OutboundMessage) -> bool: ...
```

## 本层插件接口约束（v27 总纲）

> 跨版本总纲：[INTERFACE-PLAN-v27-v44.md](../INTERFACE-PLAN-v27-v44.md)

- 本版只开放**出站层**接口，不把其他层一起搬。
- 能力名：`transport.<name>@1`。
- 核心 native（WebSocket）保持 native，**不实现 PluginManifest，不进入插件表**。
- 第三方实现本层 Protocol，通过 v27 `PluginRegistry` 注册。
- 业务只依赖 Protocol；`get()` 拿不到时回落核心 native。
- 敏感资源走 v27 权限三档（0 拒绝 / 1 询问 / 2 允许），默认 1。
- 插件任务、线程池、DB 连接池由 v27 context 提供，不允许裸 `create_task` / 裸连库。
- 插件失败写 `plugin_errors`，连续失败自动停用。
- 插件 DDL 走 `migrations/`，只支持 MySQL/SQLite，表前缀 `plugin_<name>_`。
- 热更采用 worker 进程级快照；已启用插件在新 worker 自动加载。

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v41.0** | `OutboundMessage` / `Transport` 契约 | 业务只依赖接口 |
| **v41.1** | `WebSocketTransport` native adapter | 现有发送行为不变 |
| **v41.2** | 锁/队列/重试收口到 adapter | 现有出站回归全绿 |

> 第三方出站层实现见 [v42.md](v42.md)。

## 关键约束

- WebSocket 是核心 native，不注册为插件。
- 第三方 transport 失败由 v43 回退 WebSocket。
- 核心出站只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
