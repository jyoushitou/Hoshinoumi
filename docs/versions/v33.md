## 统一约束

- 核心 native 不实现 PluginManifest、不进插件表。
- 第三方实现走 PluginRegistry；失败/停用/超时回落 native。
- 每层权限三档，默认 1（询问）。
- 插件 DDL 只允许 `plugin_<name>_` 前缀。
