## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v33.1.1.1** | 通道 `Channel` 契约 + QQ/NapCat native | QQ 行为不变 |
| **v33.1.2.1** | 通道插件接入 + 权限/错误/回落 | 插件失败回落 native |
| **v33.2.1.1** | 工具 `Tool` 契约 + 现有工具 native | 工具行为不变 |
| **v33.2.2.1** | 工具插件接入 + 越权/超时拒绝 | 失败可查 |
| **v33.3.1.1** | 存储 `StorageBackend/Repository` + MySQL/SQLite native | 现有读写不变 |
| **v33.3.2.1** | 存储插件 + 插件 DDL/迁移/事务 | 只建 `plugin_<name>_` |
| **v33.4.1.1** | 调度 `Scheduler/Trigger` + asyncio native | 现有定时不变 |
| **v33.4.2.1** | 调度插件接入 | 失败回落 native |
| **v33.5.1.1** | 出站 `Transport/OutboundMessage` + WebSocket native | 现有出站回归 |
| **v33.5.2.1** | 出站插件接入 + 锁/队列/重试收口 | 业务不直接 ws.send |
| **v33.6.1.1** | 默认链路 `RouteRegistry/FallbackChain` + native 路由 | 默认选 native |
| **v33.6.2.1** | 默认链路插件候选 + `!route` 只读视图 | 能解释为什么走 native |

## 约束

- 核心 native 不实现 PluginManifest、不进插件表。
- 插件失败/停用/超时回落 native。
- 权限三档默认 1。
