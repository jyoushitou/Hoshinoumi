# v33 系列 · 接口层收口（契约 + native + 插件接入）

> 合并原 v33–v44 六层接口：通道 / 工具 / 存储 / 调度 / 出站 / 默认链路。
> 已发布的模型层（v29/v30）和记忆层（v31/v32）不改。

## 原则

```text
每层一份 Protocol
核心 native 不注册插件
第三方实现走 PluginRegistry
拿不到/失败/停用 → 回落 native
```

## 六个子层

| 子版本 | 层 | 契约 | native |
|---|---|---|---|
| **v33.0** | 通道 | `Channel` | QQ / NapCat |
| **v33.1** | 工具 | `Tool` / `ToolSpec` | 现有工具 |
| **v33.2** | 存储 | `StorageBackend` / `Repository` | MySQL / SQLite |
| **v33.3** | 调度 | `Scheduler` / `Trigger` | asyncio |
| **v33.4** | 出站 | `Transport` / `OutboundMessage` | WebSocket |
| **v33.5** | 默认链路 | `RouteRegistry` / `FallbackChain` | 核心 native |

## 每层统一验收

```text
契约测试
native 行为不变
第三方 fake 可切换
权限/错误/任务/热更走 v28
停用/失败/超时回落 native
```

## 能力名

```text
channel.<name>@1

storage.backend.<name>@1 / storage.repository.<name>@1
scheduler.<name>@1 / schedule.trigger.<name>@1
transport.<name>@1
route.<layer>.<name>@1
```

## 非目标

- 不重新定义 v29–v32 的模型/记忆契约。
- 不把核心 native 插件化。
- 插件只能作为候选，不能改变默认核心。
