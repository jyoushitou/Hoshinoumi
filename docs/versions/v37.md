# v37 系列 · Qoder / WorkBuddy 插件与安装器

> 前置：v36 DSH 插件｜预估 4 天｜**次版本 v37.1**
>
> 目标：抽一份公共协议核心，接 Qoder / WorkBuddy 两套壳，
> 并提供三端统一的安装/卸载。

## 公共核心

```text
nao-plugin-core
  ├─ HTTP client（27004 / 27005）
  ├─ token 读取（gateway 模式）
  ├─ 工具签名（三端一致）
  └─ 错误降级（服务不可用）
```

## 次版本

| 版本 | 内容 | 天数 |
|---|---|---|
| **v37.1** | 公共协议核心 + Qoder + WorkBuddy + 安装器/卸载/文档 | 4 |

## 验收

```bash
nao install-plugin --target dsh
nao install-plugin --target qoder
nao install-plugin --target workbuddy
```

- 三端工具签名一致。
- Qoder / WorkBuddy 都能调 `nao_chat`。
- 同一份配置/token，三端共用。
- `local` / `gateway` 模式可切换。
- 卸载后无残留进程/配置。
- 安装器能检测服务未启动并提示。
