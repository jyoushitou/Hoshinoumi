# v37 系列 · 自有客户端（三）Windows 桌面

> 前置：v22 网关 / v23 多用户 API / v26 电脑 Web｜预估 6 天｜**四个次版本**
> 目标：Windows 桌面双击就能聊——会话列表、历史、实时消息、文字/图片。
> 和 v27 共用同一套 **Tauri 2 + v26 Web UI**，只换 WebView（WebView2）和系统集成。
> 排期位置：紧接 v26 电脑 Web；依赖 v22.1 / v23.3 + v26.0。

## 技术选型

| 方案 | 复用 | 体积 | 结论 |
|---|---|---|---|
| **Tauri 2 + WebView2** | v26 Web UI | 小（系统 WebView） | ✅ 默认 |
| Electron | v26 Web UI | 100 MB+ | ❌ 太重 |
| Flutter desktop | v29 手机 App | 中 | 🟡 备选：和 v27 共用一套 Flutter 工程 |
| WinUI 3 / WPF | 无 | 中 | ❌ 重写 UI，和 Web 分叉 |

**WebView2**：Win10 22H2 / Win11 一般已带；安装器带 Evergreen Bootstrapper，离线包可选。

## 关键设计

- **认证**：gateway JWT；token 存 **Windows Credential Manager**，不写明文配置；刷新失败回登录页。
- **实时**：优先 WebSocket；断线指数退避；重连后按 `last_message_id` 补洞。
- **通知**：Windows Toast（WinRT）；窗口聚焦/专注助手开启时不弹；免打扰时段静音。
- **托盘**：关窗 = 最小化到托盘；菜单：打开 / 静音 / 退出。
- **单实例**：命名 Mutex；第二次启动激活已有窗口。
- **开机自启**：注册表 `Run` 或启动任务；可在设置里关。
- **高 DPI**：Per-Monitor V2；WebView2 缩放跟随系统；中文输入法实测（微软拼音/搜狗）。
- **数据目录**：`%APPDATA%\nao`、`%LOCALAPPDATA%\nao`；卸载不删聊天记录。
- **安全**：只连 gateway / 本机 API；token 不进日志；不关证书校验；可选 Authenticode 签名减少 SmartScreen 提示。

## 验收

```powershell
# 安装 MSI 后
nao-desktop.exe
# 登录 → 会话 → 发消息 → 手机/QQ 收到
```

- 关窗进托盘；新消息 Toast；开机自启；断网重连不丢消息。
- 换一个账号登录：会话/记忆切到该账号，A/B 不串。
- Win10 22H2 / Win11 各跑一遍；高 DPI 150%/200% 不糊；中文输入正常。

## 风险

| 风险 | 处理 |
|---|---|
| 没装 WebView2 | 安装器自动装 Evergreen Runtime；离线包兜底 |
| SmartScreen 拦截 | 代码签名（可选）；文档写"更多信息→仍要运行" |
| 托盘/Toast 被安全软件拦 | 不写敏感目录；失败降级为窗口内提示 |
| token 泄露 | Credential Manager；日志脱敏 |
| 和 v26 分叉 | 共用同一套 Tauri 工程 + Web 构建；只分平台配置 |

## 不做

- 不在桌面端做语音/视频通话（留给 v40/v41 之后的客户端）。
- 不内嵌模型/数据库；桌面端只是客户端。
- 支持多用户登录（JWT `sub=user_id`）；同一时间一个活跃账号。
- 换账号登录后，会话/记忆/日程必须切到该账号，不串。
