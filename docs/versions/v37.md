## v37.3.1.1 · 统计与 v37 遗留 bug 收尾

### 统计

```text
!stats all        命令/消息/模型用量
!plugin errors    插件错误
!db               表数量 / schema
!version          当前版本
```

汇总输出：

```text
本阶段完成版本
新增命令
新增表
测试数量
未关闭 bug 数
```

### 修遗留 bug

```text
v37 开发中记下的 P0/P1/P2（附 v33–v37 汇总）
TODO / FIXME
插件/权限/热更/客户端已知问题
```

规则：

- 只修 bug，不加新功能。
- 每个 bug 一条回归测试。
- 修不完的降级为“已知限制”，写进文档。
- 不为了让统计好看而删测试或隐藏错误。

### 验收

```text
1. 全量测试 0 失败
2. 没有未关闭的 P0/P1
3. 统计报告能列出本阶段版本/命令/表/测试数
4. 已知限制有文档，不静默
```
