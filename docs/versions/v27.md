# v27 系列 · 通道层接口

> 核心：只定义第三方通道实现接入的接口。
> QQ / NapCat 是核心 native 通道，不是插件。

```python
class Inbound(Protocol):
    user_id: str
    channel: str
    text: str


class Channel(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def send(self, target: str, text: str) -> bool: ...
    def on_message(self, handler) -> None: ...
```

规则：

- QQ / NapCat 不注册到插件表；插件只能新增 Web / 微信 / Webhook 等通道。
- 插件通道失败/卸载不影响 QQ 通道。
- 核心通道只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
