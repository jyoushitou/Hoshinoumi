# v27 系列 · 自有客户端（二）Linux 桌面

> 前置：v22 网关 / v23 多用户 API / v26 电脑 Web｜预估 6 天｜**四个次版本**
> 目标：Linux 桌面双击就能聊——会话列表、历史、实时消息、文字/图片。
> 不是重写一套 UI：把 v26 的 Web 构建产物装进 **Tauri 2** 壳，壳只做登录/托盘/通知/打包。
> 排期位置：紧接 v26 电脑 Web；依赖 v22.1 / v23.3 + v26.0。

## 技术选型

| 方案 | 复用 | 体积 | 结论 |
|---|---|---|---|
| **Tauri 2 + WebKitGTK** | v26 Web UI | 小（系统 WebView） | ✅ 默认 |
| Electron | v26 Web UI | 100 MB+ | ❌ 太重 |
| Flutter desktop | v29 手机 App | 中 | 🟡 备选：Linux 桌面成熟度一般 |
| PySide6 | 无 | 中 | ❌ 重写 UI，和 Web 分叉 |

**先做 1 天技术验证**：WebKitGTK 的 fcitx5 中文输入、Wayland 托盘、通知。
任一不过就切 Flutter desktop（复用 v29 的工程）。

## 关键设计

- **认证**：走 gateway JWT；token 存 **libsecret**（Secret Service），不写明文配置；刷新失败回登录页。
- **实时**：优先 WebSocket；断线指数退避；重连后按 `last_message_id` 补洞。
- **通知**：libnotify/DBus；窗口聚焦时不弹；免打扰时段静音。
- **托盘**：关窗 = 最小化到托盘；菜单：打开 / 静音 / 退出。
- **单实例**：DBus 激活已有窗口，避免双开。
- **中文输入**：fcitx5 / ibus 实测；Wayland 和 X11 各跑一遍。
- **数据目录**：`$XDG_CONFIG_HOME/nao`、`$XDG_CACHE_HOME/nao`；卸载不删聊天记录（用户数据）。
- **安全**：只连 gateway / 本机 API；token 不进日志；不关证书校验。

## 验收

```bash
sudo apt install ./nao-desktop_*.deb
nao-desktop
# 登录 → 会话 → 发消息 → 手机/QQ 收到
```

- 关窗进托盘；新消息系统通知；开机自启；断网重连不丢消息。
- 换一个账号登录：会话/记忆切到该账号，A/B 不串。
- Wayland / X11 各跑一遍；fcitx5 中文输入正常。

## 风险

| 风险 | 处理 |
|---|---|
| WebKitGTK 版本差异 | 最低 Ubuntu 22.04 / Debian 12；打包声明依赖 |
| Wayland 托盘/通知 | 先 X11 兜底，Wayland 单独测 |
| token 泄露 | libsecret；日志脱敏 |
| 和 v26 Web 分叉 | 共用同一份 Web 构建产物，壳只加 bridge |

## 不做

- 不在桌面端做语音/视频通话（留给 v38/v39 之后的客户端）。
- 不内嵌模型/数据库；桌面端只是客户端。
- 支持多用户登录（JWT `sub=user_id`）；同一时间一个活跃账号。
- 换账号登录后，会话/记忆/日程必须切到该账号，不串。
