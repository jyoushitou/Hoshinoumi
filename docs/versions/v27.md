# v27 系列 · QQ 空间

> 前置：v17（出站层 + 调度）、v18（记忆分量）｜预估 11 天｜**六个次版本**
>
> 她发自己的说说，**并且会和认识的人互动**——点赞、评论。
> 互动不是「随便点」，而是**和聊天记忆联动**：聊过天的人，她才去互动。
>
> **多用户**：每个 `user_id` 绑定自己的 QQ 空间账号（cookie）；说说/互动只作用于该账号；
> 没绑定的 user 关闭此功能。A 的说说/好友绝不出现在 B 的空间操作里。

## 为什么做这个

微信/QQ 聊天是「一对一」；QQ 空间是**公开的表达 + 社交**。
她在那儿不只是发东西，而是**和熟人打交道**——这是「有生活」的最后一块。

## 第一步：可行性（1 天，可能直接砍掉）

QQ 空间没有公开 API。可能的路径：

| 方案 | 做法 | 风险 |
|---|---|---|
| **A. 带 cookie 的 HTTP 接口**（主选） | 用你登录后的 cookie 调 `qzone.qq.com` 的接口 | cookie 会过期；接口可能改 |
| B. 浏览器自动化（退路） | Playwright 打开空间页面操作 | 慢、重、易被风控 |
| C. 不做 | 只在聊天里说「今天想发个说说」 | 零风险，但没真的发 |

**第 1 天就验证 A**：能不能发一条纯文本、能不能看到好友动态。
拿不到就退 B，再不行就 C（这一版缩水成「她会在聊天里念叨想发什么」）。

## 红线（写死在代码里）

| 红线 | 原因 |
|---|---|
| **每天最多 1 条说说** | 刷屏会被举报 |
| **点赞/评论只对「有记忆的人」** | 陌生人一律不互动——这是防封号的核心 |
| **每天互动 ≤ 5 次**（赞 + 评合计） | 高频互动是最容易被判定为机器人的行为 |
| **默认关闭**（`enabled: false`） | 用户不主动开，就绝不发也不互动 |
| **不发自拍/真人图**（有图只发 ACG 图） | 避免伪造真人形象 |
| **不主动加好友、不私信** | 只做「公开可见的轻互动」 |
| 内容自检：不含隐私、真实地址、政治 | 公开内容风险最高 |

## v27.3 · 互动：点赞与评论（3 天）

> 从「只发」升级成「会社交」。**但只对自己认识的人。**

### 谁能被互动（白名单怎么来）

```python
# 只处理「有记忆的人」：
#   relations 表里存在，且亲密度 > 0.2
#   —— 说明跟主人聊过天、或者被她记住过
allowed = {tid for tid in relations if intimacy(tid) > 0.2}
```

**陌生人的动态一律跳过**，哪怕内容再有意思。

### 互动规则

| 动作 | 规则 |
|---|---|
| **点赞** | 只对白名单；每天 ≤ 5 次；同一个人 7 天内 ≤ 2 次 |
| **评论** | 只对白名单；每天 ≤ 2 条；同一人 7 天内 ≤ 1 条 |
| 评论内容 | ≤ 30 字，只接「生活类」内容（吃/睡/累/考试/生病） |
| 跳过 | 政治、争吵、募捐、广告、悲伤事件（丧事/病危） |
| 允许静默 | 拿不准就不互动——**不互动比互动错安全** |

### 单元

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | `qzone_feed()` 解析出 `{uin, nickname, content, time, post_id}` | 字段齐 |
| U2 | 白名单过滤（读 relations） | 陌生人被跳过 |
| U3 | 点赞动作 + 计数限额 | 超限不动 |
| U4 | 评论生成（接 v18 记忆，能提「你上次说…」） | 评论像人话 |
| U5 | 内容安全：跳过敏感/悲伤话题 | 命中的不评 |

## v27.4 · 记忆联动（2 天）

> **核心**：空间里发生的事，要进她的记忆；聊天里聊过的人，才好去互动。

### 双向联动

```
空间 → 记忆：
   看到好友发了「住院了」→ 写一条记忆（importance 中/重）
   → 下次聊天时她可能问「你前几天发的那个，还好吗」

记忆 → 空间：
   聊天里说过「我妈住院」→ 那个人 weight 高 → 空间里更愿意给他点赞
   亲密度高的好友发动态 → 优先级更高
```

### 单元

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 空间动态 → `memories`（kind=`qzone`，带 weight） | 能检索到 |
| U2 | 互动记录 → `qzone_interactions` 表（谁、什么、什么时候） | 可查 |
| U3 | 亲密度影响互动优先级（高的先看） | 排序正确 |
| U4 | 评论里能引用记忆（「你上次说腰疼」） | 不是空话 |
| U5 | 同一个人：空间 + 聊天用**同一个 target_id** | 记忆不分裂 |

### 新表

```sql
CREATE TABLE qzone_interactions (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    target_id   VARCHAR(64) NOT NULL,     -- 和 relations/memories 同一个 id
    action      ENUM('like','comment') NOT NULL,
    post_id     VARCHAR(64) NOT NULL,
    content     VARCHAR(200) NULL,        -- 评论内容
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    KEY idx_qi_target_time (target_id, created_at),
    KEY idx_qi_post (post_id)
);
```

### 红线（这一版最重要）

| 红线 | 原因 |
|---|---|
| **绝不评论丧事/病危/分手** | 说错一句就是灾难 |
| **评论不提「我记得你说过」除非 weight ≥ 0.6** | 记错了更尴尬 |
| **同一人 7 天最多 1 条评论** | 防刷屏 |
| 拿不准就**不互动** | 沉默无害 |

## 验收（系列整体）

| 项 | 标准 |
|---|---|
| 能发 | 空间里出现一条 |
| 发布频率 | 一周不超过 7 条 |

| **记忆联动** | 空间看到的事，聊天里能提起来 |

## 风险与处理

| 风险 | 处理 |
|---|---|
| cookie 过期 | 报错提示重新登录；不重试 |
| 被风控/封号 | 限额 + 只对熟人 + 只做轻互动；发现异常立刻停 |
| **评论说错话** | 内容自检 + 跳过敏感话题 + 拿不准不评 |
| 记忆串人 | 空间和聊天统一用 `target_id` |
| 用户不想公开 | 默认关闭，`enabled: false` |
