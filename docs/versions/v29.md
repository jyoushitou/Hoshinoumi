# v29 系列 · 存储层接口实现

> 核心：把 MySQL / SQLite 与现有仓储包成 `StorageBackend` / `Repository` 实现。
> 核心 backend 是 native，不注册为插件。

```python
class StorageBackend(Protocol):
    name: str
    async def execute(self, sql: str, params: tuple) -> list[dict]: ...
    async def transaction(self): ...


class Repository(Protocol):
    async def get(self, user_id: str, key: str) -> dict | None: ...
    async def put(self, user_id: str, key: str, value: dict) -> None: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v29.0** | `StorageBackend` / `Repository` 契约 | 业务只依赖接口 |
| **v29.1** | `MySQLBackend` native adapter | 现有 MySQL 行为不变 |
| **v29.2** | `SQLiteBackend` native adapter | 降级路径不变 |
| **v29.3** | 现有 repo_* 收口到 Repository | 业务不再拼 SQL |
| **v29.4** | 第三方 backend adapter + fake 测试 | 新 backend 不改业务 |

## 关键约束

- MySQL / SQLite 是核心 native，不注册为插件。
- 第三方 backend 失败由 v32 回退核心 backend。
- 核心存储只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
