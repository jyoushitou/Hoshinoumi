# v29 系列 · 运维通道（三）有限写

> 前置：v19（bash 只读）+ v20（agent）｜预估 2 天｜**默认关闭**

## 目标

先放开**最常用、后果可控**的几个写命令，但每次执行前**必须备份**。

```
你：把服务重启一下
她：即将执行 docker restart nao-bot
    已备份：容器状态 + 当前日志尾部 → backups/20261110-1432/
    回复「确认」执行

你：确认
她：✅ 已重启。容器状态：Up 3 seconds
```

## 为什么先只开这几个

| 命令 | 后果 | 为什么敢开 |
|---|---|---|
| `docker restart <容器>` | 服务短暂中断 | 状态可查、失败可再拉起 |
| `systemctl reload <服务>` | 重载配置，不中断 | 比 restart 温和 |
| 轮转日志（`truncate`/rename） | 释放磁盘 | 原文件先备份 |
| 清空缓存目录（指定路径） | 缓存重建 | 路径白名单 + 先备份 |

**不开**：`rm` 任意文件、`apt`、`/etc` 修改、DDL、防火墙。

## 写命令白名单

```python
WRITE_COMMANDS = {
    "restart":  ["docker", "restart", "{name}"],          # name 必须在容器白名单
    "reload":   ["systemctl", "reload", "{name}"],        # name 必须在服务白名单
    "rotate":   ["mv", "{file}", "{file}.{ts}"],          # 只允许移动日志文件
    "clearcache": ["find", "{dir}", "-mindepth", "1", "-delete"],  # dir 必须在白名单
}
```

| 约束 | 说明 |
|---|---|
| `{name}` | 只能取预配置列表里的值（`nao-bot`、`mysql` 等） |
| `{file}` | 只能是 `logs/` 下的文件 |
| `{dir}` | 只能是 `data/cache` 这类指定目录 |
| 仍然 `shell=False` | 注入无效 |

## 强制备份（本版核心）

**备份失败 = 拒绝执行**，没有例外。

| 命令 | 备份什么 |
|---|---|
| `restart` | `docker inspect` 快照 + 最近 200 行日志 |
| `reload` | 服务状态 + 当前配置文件副本 |
| `rotate` | 原日志文件（移动前先 copy） |
| `clearcache` | 目录清单 + 文件总大小（不备份内容，太大） |

备份目录：

```
data/backups/20261110-1432/
  manifest.json      # 命令、时间、备份内容、执行结果
  state.json         # 服务/容器快照
  app.log.tail       # 日志尾部
```

## 二次确认

```
她：即将执行 <命令>，已备份到 <id>
    回复「确认」在 60 秒内生效，其他内容视为取消
```

| 规则 | 说明 |
|---|---|
| 确认词 | 精确匹配「确认」 |
| 有效期 | 60 秒 |
| **agent 模式** | 同样要确认，模型不能自批 |
| 取消 | 其他消息或超时 |

## 与 v20.3 的分工

| | v22（本版） | v20.3 |
|---|---|---|
| 范围 | 4 个写命令 | 完整分级（W1–W4） |
| 备份 | 有（单次快照） | 有（体系化 + 保留策略） |
| 回滚 | **不做**（手动看备份） | `!rollback` 一键回滚 |
| 确认 | 有 | 有 |

**v22 只保证「出事有东西可查」，v20.3 才保证「一键回去」。**

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `write_enabled` | false | 写命令总开关 |
| `write_confirm_sec` | 60 | 确认有效期 |
| `write_names` | `nao-bot,mysql` | 允许操作的容器/服务名 |
| `write_log_dir` | `logs` | 允许轮转的日志目录 |

## 验收

- [ ] `docker restart nao-bot` 前生成备份（状态 + 日志尾部）
- [ ] 备份失败时**拒绝执行**
- [ ] 60 秒内没确认 → 取消
- [ ] 非白名单名字（如 `mysql-prod`）被拒绝
- [ ] agent 发起的写命令也要人确认
- [ ] 每条写操作进审计（含 backup id）
- [ ] `rm`/`apt`/`/etc` 类命令仍然拒绝

## 风险

| 风险 | 处理 |
|---|---|
| 重启把机器人弄挂 | 备份里有状态；可 SSH 用 `docker start` 拉起 |
| 轮转日志丢内容 | 先 copy 再移动 |
| 误确认 | 60 秒窗口 + 明确写出命令 |
| 备份占磁盘 | 只留最近 10 份 |
