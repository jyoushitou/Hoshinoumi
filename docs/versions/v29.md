# v29 系列 · 存储层接口

> 核心：只定义第三方存储实现接入的接口。
> MySQL / SQLite 与现有仓储是核心 native 实现，不是插件。

```python
class StorageBackend(Protocol):
    name: str
    async def execute(self, sql: str, params: tuple) -> list[dict]: ...
    async def transaction(self): ...


class Repository(Protocol):
    async def get(self, user_id: str, key: str) -> dict | None: ...
    async def put(self, user_id: str, key: str, value: dict) -> None: ...
```

规则：

- 核心 backend 不注册到插件表；插件只能新增外部 backend / 只读副本。
- 插件存储失败时回退核心 backend。
- 核心存储只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
