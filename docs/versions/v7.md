# v7 · 记忆地基

> 前置：v6 ｜ 预估 3 天 ｜ **本版动数据库**

## 目标

把 `events` 扩成记忆主表，为后面所有「记得住」的功能打底。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U3 | B8 B10 B14 B15 | 扩列（kind/dedupe_key/last_seen/importance）、原文全留、迁移去重、写入去重 |
| U6 | B9 | 对象画像（昵称/关系/喜好/禁忌/生日） |
| U17 | E32 E33 | 单实例锁、systemd、依赖检查；报错不进聊天 |

## 涉及文件

`infra/schema.py`（新建）、`infra/repo_memory.py`、`scripts/migrate_v7.py`（新建）、
`run.py`（单实例）、`docs/`

## 实施步骤

1. **备份**：`mysqldump ... events user_memory` 
2. 写 `ALTER TABLE`（6 列 + 2 索引），先 dry-run
3. 回填 `dedupe_key = md5(kind + 归一化文本)`，同键合并
4. 上限按 kind 分开（life 60 / user 30 / 其他 20）
5. B9 画像：`kind='profile'` 一行 JSON
6. E32/E33：单实例文件锁、报错只进日志

## 验收

- [ ] `events` 扩列成功，历史 100 条回填 `dedupe_key`
- [ ] 同一件事说三遍，只留一条且 `hit_count=3`

## 风险

**必须**：备份 → dry-run → `--apply` → 复查。迁移脚本要能重复执行（幂等）。
