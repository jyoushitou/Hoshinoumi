## 接口

```text
GET  /api/plugins
POST /api/plugins/install   (source=file|url|manifest|manual)
POST /api/plugins/<id>/toggle
POST /api/plugins/<id>/approve
POST /api/plugins/<id>/reject
```

约束：

```text
owner-only
包后缀 .hoshinoumi / .zip
单包 20 MB / 解压 50 MB / 500 文件
plugin.json 必填 id/name/version/apiVersion/entry
权限白名单 read-only/network/filesystem/db/notifications/finance
finance 权限进入待审批
重复 id 返回 409
非法 ZIP / 路径穿越 / 未知权限返回 400
```
