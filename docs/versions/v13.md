## 验收

- [ ] 她会欲言又止：「算了。」

## 红线

所有负面机制**必须带恢复路径和上限**（冷战 ≤1 天、怨念 ≤1 次/周）。
没有恢复机制的冷淡就是情感操控。

### U22 工具调用（F34）

用**提示词协议**而不是 function calling——换模型不用改代码：

```
需要工具时单独一行：@tool: recall(答辩)
拿到结果后正常回话，别再输出 @tool
```

| 工具 | 作用 |
|---|---|
| `recall` | 检索记忆（BM25+关键词，取前 3 条） |
| `remember` | 记一件事（kind='event'，importance=4） |
| `agenda_add` | 记日程（复用 v10 的时间解析） |
| `search_images` | 搜图库，返回找没找到 |

**最多一轮**：拿到工具结果后允许再调一次模型；不会无限套娃。
