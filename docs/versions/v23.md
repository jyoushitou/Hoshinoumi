# v23 系列 · 自有客户端（二）手机 App

> 前置：v19（后端 API 与 Web 已完成）｜预估 10 天｜**五个次版本**
>
> 把浏览器里那套搬进手机：能聊、能收推送、能管理她的事。
> **后端一行不改**——完全复用 v19 的 API。

## 次版本拆分

| 版本 | 内容 | 天数 |
|---|---|---|
| v23.0 | Flutter 工程 + 登录 + 会话列表 | 2 |
| v23.1 | 聊天页（复用 v19 的 API） | 2 |
| v23.2 | **推送通知**（她主动说话时响） | 2 |
| v23.3 | App 端功能面板（日记/书架/定时/记忆） | 2 |
| v23.4 | 收尾：后台保活 + iOS PWA 兜底 + 修 bug | 2 |

## v23.0 · 工程与登录（2 天）

| 单元 | 内容 | 验收 |
|---|---|---|

## v23.2 · 推送通知（2 天）

| 单元 | 内容 | 验收 |
|---|---|---|

## 涉及文件（App 版）

| 文件 | 作用 |
|---|---|
| `app/`（新目录） | Flutter 工程 |
| `app/lib/api.dart` | 调 v19 的 REST |
| `app/lib/chat.dart` | 聊天页 |
| `app/lib/push.dart` | 长连接 / 通知 |

## 验收（App 版整体）

| 项 | 标准 |
|---|---|
| 能聊 | App 里发消息、收到回复 |
| 推送 | 锁屏时能收到她的消息 |
| 一致性 | App 里说的事，QQ / Web 里都记得 |
| 后台 | 关屏 30 分钟仍能收 |

## 风险

| 风险 | 处理 |
|---|---|
| Flutter 环境重 | 先 Android；iOS 用 PWA |
| 国产 ROM 杀后台 | 引导加白名单；失败就退回 PWA |
| 推送延迟 | 长连接 + 心跳，不依赖系统推送 |
