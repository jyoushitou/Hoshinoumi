# v34 系列 · 学习规划 / 计划表

> 位置：v33 接口层收口之后。
> 本版为学习规划。
> 目标：把“本周计划表”做成一等能力，而不是塞几十条 `!cron`。
> 布局类似课程表：7 天 × 最多 10 节；格子里是学习任务，不是课程元数据。

## 目标

```text
一张周计划表：7 天 × 若干格
每格是任务，不是课程表
任务可标记：待做 / 完成 / 跳过 / 顺延
按周生效，支持临时改计划
到点提醒，但不刷屏
```

## 它不是什么

```text
不是教务课程表：没有老师、教室、学期课程结构
但布局就是课程表式网格：周一到周日 × 第1-10节
不是番茄钟：不强制计时
不是通用待办：围绕“这一周的学习计划”组织
```

格子里的内容可以是：

```text
课:Web实验（核验Web七八）
实:Java四
Linux资料·重定向
库中级一 视图
概率第1章
活动
```

## 数据模型：一周一行，7 个日列，节数不定

不写 `cron_tasks`；`study_plans` 一张表，**周一到周日各一列**。

```sql
CREATE TABLE study_plans (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id     VARCHAR(64) NOT NULL DEFAULT '__owner__',
    week_start  DATE NOT NULL,
    title       VARCHAR(128) NOT NULL DEFAULT '',
    monday      TEXT NULL,
    tuesday     TEXT NULL,
    wednesday   TEXT NULL,
    thursday    TEXT NULL,
    friday      TEXT NULL,
    saturday    TEXT NULL,
    sunday      TEXT NULL,
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
                ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_study_week (user_id, week_start)
);
```

- **一周一行**，不是固定 10 行。
- `monday..sunday` 是 7 个日列。
- 每列是一个 JSON 数组，长度每天可以不同：

```json
{
  "monday": [
    {"no": 1, "time": "09:00", "subject": "Linux",
     "task": "文件系统", "kind": "review", "status": "todo"}
  ],
  "wednesday": [
    {"no": 1, "time": "08:00", "subject": "Java", "task": "实:Java四",
     "kind": "lab", "status": "todo"},
    {"no": 2, "time": "10:00", "subject": "概率", "task": "第1章",
     "kind": "review", "status": "todo"},
    {"no": 3, "time": "14:00", "subject": "Linux", "task": "综合卷①",
     "kind": "practice", "status": "todo"}
  ],
  "sunday": []
}
```

- `no` 只是当天顺序，不要求 1..10 连续。
- `time` 每天可以不同；没有固定“第10节”。
- 空/NULL 表示当天没有安排。
- `status`：todo / done / skipped / moved。
- 顺延/调课直接改对应日列的 JSON，不建第二张表。
- `!cron` 不会因为导入计划变长。

`week_start` 必须是周一；同一周只能有一行。

## 次版本

| 版本 | 内容 | 验收 |

| **v34.0** | `study_plans` 单表 + 7 个日列 + 迁移 | 旧库幂等；一周一行；每天节数可变 |

## 命令

```text
!plan                       本周概览
!plan today                 今天
!plan week 2026-11-16       指定周
!plan import <json>         导入周计划
!plan add <day> <格> <内容>
!plan done <id>             完成
!plan skip <id>             跳过
!plan move <id> <day> <格>  顺延/改期
!plan export                导出
```

全部仅主人可用。

## 执行规则

```text
到格子的开始时间
→ 查今天该格未完成任务
→ 发送一次提醒
→ 同一天同一任务不重复
```

- 默认提前 10 分钟。
- 空/已完成/已跳过不发。
- 考试/DDL 可以单独设更长提前量。
- 计划提醒和 `cron_tasks` 分开，不混列表。

## 顺延规则

截图里的备注：

```text
临时事务用当周第 10 格消化
```

v34.2 支持：

```text
任务错过 → 可手动 move 到本周末尾空闲格
不改原计划模板
顺延写 study_item_events
```

不自动把所有未完成任务堆到第二天，避免列表越滚越大。

## 验收

```text
1. 导入第 12 周计划，!plan week 能看到 7 天
2. 空/— 不显示、不提醒
3. 到点只提醒一次
4. !plan done / skip / move 能改状态
5. 临时调课只影响当天，不改模板
6. 第 12 周结束后不再提醒
7. !cron 列表不增加几十条
```

## 非目标

- 不做教务系统登录。
- 不做课程表 OCR（后续可加）。
- 不强制番茄钟计时。
- 不替代 `!cron`；考试/DDL 仍可同时用 cron。
- 不做多人共享计划；先单主人。
- 不提前拆 plans/items/events 多表；v34.0 就是 `study_plans` 一张表，7 个日列，每天的数组长度不定。
