# v34 系列 · 学习规划

> 大版本 v34。次版本从 1 开始，次次版本从 1 开始，补丁从 1 开始。
> 目标：把“本周计划表”做成可导入、可执行、可顺延、可复盘的一等能力。

## 1. 范围

### 要做

```text
一张 study_plans 表：一周一行，周一到周日 7 列
每列是 JSON 数组，每天节数可变
周计划导入/查看
任务完成/跳过/顺延
到点提醒（只提醒一次）
周复盘/统计
```

### 不做

```text
不接教务系统
不做课程表 OCR（后续可加）
不强制番茄钟
不建 plans/items/events 多表
不占 cron_tasks
```

## 2. 数据模型

```sql
CREATE TABLE study_plans (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id     VARCHAR(64) NOT NULL DEFAULT '__owner__',
    week_start  DATE NOT NULL,
    title       VARCHAR(128) NOT NULL DEFAULT '',
    monday      TEXT NULL,
    tuesday     TEXT NULL,
    wednesday   TEXT NULL,
    thursday    TEXT NULL,
    friday      TEXT NULL,
    saturday    TEXT NULL,
    sunday      TEXT NULL,
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
                ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_study_week (user_id, week_start)
);
```

每格 JSON：

```json
{
  "no": 1,
  "time": "09:00",
  "subject": "Linux",
  "task": "文件系统",
  "kind": "review",
  "status": "todo",
  "estimate_min": 45,
  "actual_min": 0,
  "note": "",
  "notified_at": null
}
```

规则：

```text
week_start 必须是周一
no 只是当天顺序，不要求连续
time 每天可不同
空/NULL 表示当天没安排
status: todo / done / skipped / moved
notified_at 用于去重，不另建提醒日志表
```

## 3. 命令

```text
!plan                       本周概览

!plan week 2026-11-16       指定周
!plan import <json>         导入周计划
!plan add <day> <时间> <内容>
!plan done <day> <no>
!plan skip <day> <no>
!plan move <day> <no> <to_day> <to_no>
!plan export                导出

```

## 5. 开发思路

### 5.1 单表而不是多表

- 周计划是“读多写少”的个人数据，一周一行足够。
- 不拆 items：避免 join、避免跨天移动时多表事务。
- 所有修改是“读 JSON → 改 → 写回”，用 `updated_at` 做冲突提示。
- 提醒去重也放 JSON，避免新增表。

### 5.2 导入

```text
JSON 文本
→ json.loads
→ 校验 week_start 是周一
→ 校验每天数组、no 唯一、time HH:MM
→ upsert
→ 返回导入条数
```

不做 OCR；截图/表格先由用户或脚本转 JSON。

### 5.3 提醒

```text
每 60s：
  取本周 plan
  取今天
  找 todo 且 time <= now
  且 notified_at 为空
  → 发送
  → 写 notified_at
```

不在 `cron_tasks` 建几十条；避免污染钩子列表。

### 5.4 顺延

```text
move(day,no,to_day,to_no)
→ 源数组删除
→ 目标数组插入/追加
→ 保留 note="moved from ..."
```

不自动把所有未完成任务堆到第二天；由用户决定。

## 6. 风险

- JSON 并发写覆盖：单主人低并发；加 updated_at 比较，冲突提示重读。
- 时区：统一 Asia/Shanghai。
- 提醒重复：notified_at 必须持久化。
- QQ 文本过长：按天分页/截断。

## 7. 总验收

```text
1. 导入一周计划，7 天可读
2. 空白天不显示
3. done/skip/move 正确
4. 到点只提醒一次
5. 重启后不重复提醒
6. 周日统计完成率
7. 不增加 cron_tasks 行
```
