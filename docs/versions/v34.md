# v34 系列 · 学习规划

> 从 `v34.1.1.1` 开始。

## 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| **v34.1.1.1** | `study_plans` 单表：周一到周日 7 列、节数可变 | 一周一行；旧库幂等 |
| **v34.1.2.1** | `!plan import/list/today/week` | 导入周计划，7 天可读 |
| **v34.1.3.1** | 完成/跳过/顺延 + 到点提醒 + 去重 | 任务状态可改；每格只提醒一次 |
| **v34.1.4.1** | 临时事务/顺延/周复盘/统计 | 不改模板；周结束归档 |

## 约束

- 一张 `study_plans` 表，不拆多表。
- 每天节数可变；空为 NULL。
- 自动提醒不刷屏；命令才回详情。
