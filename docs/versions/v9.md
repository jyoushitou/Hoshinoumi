# v9 · 她有自己的生活

> 前置：v7 ｜ 预估 4 天 ｜ 引入状态与时间线

## 目标

你不在的时候，她也在活。

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U4 | C15 C16 | 状态向量（mood/energy/loneliness/affinity）+ 状态→自然语言 |
| U7 | C17 | 每日生活事件（学生会 / 小咪 / 练琴 / 天气） |
| U11 | D24 | 日记回流：当天日记 → 次日记忆与心情 |

## 涉及文件

`life/state.py`（新建）、`life/events.py`（新建）、`core/state.py`、
`ai/prompt.py`、`schedule/runner.py`、`diary/generate.py`

## 实施步骤

1. 状态向量：`s ← s + k(base−s) + Δ事件`，每小时推进
2. 状态 → 一句自然语言，注入 prompt（数值不可见）
3. 每日生活事件：写 `events(kind='life')`，1~3 条，7 天内去重
4. 日记回流：凌晨 3 点日记压成 2~3 条记忆
5. 状态 clamp + 每天重置基线

## 验收

- [ ] 聊天时她主动提「今天小咪把杯子打碎了」
- [ ] 三天不理她，语气会变淡
- [ ] 任何地方都看不到数值

## 风险

状态漂移容易让人设崩，需要上限和每日基线重置。
