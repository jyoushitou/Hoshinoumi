# v31 系列 · 出站层接口

> 核心：只定义第三方传输实现接入的接口。
> WebSocket 出站是核心 native 实现，不是插件。

```python
class OutboundMessage(Protocol):
    target: str
    text: str
    meta: dict


class Transport(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def send(self, msg: OutboundMessage) -> bool: ...
```

规则：

- WebSocket 出站不注册到插件表；插件只能新增 HTTP / Webhook / MQ 传输。
- 插件传输失败时回退 WebSocket。
- 核心出站只能在启动前由 `features.json` / `NAO_FEATURES` 关闭。
