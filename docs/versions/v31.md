# v31 系列 · 出站层接口实现

> 核心：把 WebSocket 出站包成 `Transport` 实现，并暴露第三方传输接口。
> WebSocket 是核心 native，不注册为插件。

```python
class Transport(Protocol):
    name: str
    async def start(self) -> None: ...
    async def stop(self) -> None: ...
    async def send(self, msg: OutboundMessage) -> bool: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v31.0** | `OutboundMessage` / `Transport` 契约 | 业务只依赖接口 |
| **v31.1** | `WebSocketTransport` native adapter | 现有发送行为不变 |
| **v31.2** | 锁/队列/重试收口到 adapter | 现有出站回归全绿 |
| **v31.3** | 第三方 transport adapter + fake 测试 | 新传输不改业务 |

## 关键约束

- WebSocket 是核心 native，不注册为插件。
- 第三方 transport 失败由 v32 回退 WebSocket。
- 核心出站只能启动前通过 `features.json` / `NAO_FEATURES` 关闭。
