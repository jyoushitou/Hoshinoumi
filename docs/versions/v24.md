# v24 系列 · 插件接口实现（含 v24.4–v24.8 书籍链路与抓包分析）

> 核心：实现第三方插件接入所需的接口和注册表。
> **本层不实现任何功能**：只定义契约和注册表，不提供任何实现；具体 provider / channel / tool / storage 由核心或第三方开发者实现。
> 现有功能仍是核心 native；没有插件时核心默认链路照常工作。
> 欢迎其他开发者按契约提交实现。

```python
class PluginManifest(Protocol):
    name: str
    version: str
    capabilities: set[str]
    priority: int


class PluginRegistry(Protocol):
    def register(self, manifest: PluginManifest, factory) -> None: ...
    def get(self, capability: str, name: str): ...
    def list(self) -> list[PluginManifest]: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v24.0** | `PluginManifest` / `PluginRegistry` 契约 + 内存注册表 | 能注册/查找/列出测试插件 |
| **v24.1** | 能力字符串规范 + 版本校验 + 冲突检测 | 同名/同能力冲突可解释 |
| **v24.2** | 第三方 adapter 加载入口（只加载，不实现具体插件） | 加载失败不影响核心 |
| **v24.3** | 核心 native 不注册测试 + 文档/收尾 | 核心不出现在插件表 |

## 关键约束

- 核心实现不实现 `PluginManifest`，不进入 `PluginRegistry`。
- `get()` 找不到插件时返回 `None`，由调用方走核心。
- 插件注册失败只记录，不阻塞启动。
- 核心功能只能通过启动前 `config/features.json` / `NAO_FEATURES` 关闭。

## v24.4 · 搜索「十日终焉」无结果

**只修一件事**：番茄搜索命中率。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 固定「十日终焉」搜索 HTML 快照，不依赖实时网络 | 回归测试稳定 |
| U2 | 检查关键词编码、请求头、搜索 URL、结果选择器 | 能拿到候选列表 |
| U3 | 搜索无结果时走番茄搜索页兜底，并给出可解释原因 | 不再无条件回「给我链接」 |

**验收**：输入「去看看十日终焉」→ 能命中 A 页面或给出候选，不直接要求链接。

## v24.5 · 链接标题识别成「这本小说」

**只修一件事**：从番茄链接解析真实书名，禁止回退成「这本小说」。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 链接入库时抓取页面 `<title>` / 作品名节点 | 样本 A/B 都能取到书名 |
| U2 | 标题清洗：去掉「完整版在线免费阅读」「番茄小说」等后缀 | A = 十日终焉；B = 领主：我在苦痛世界，养成少女 |
| U3 | 解析失败时保留 URL 并明确报错，不伪造书名 | 不出现《这本小说》 |
| U4 | 作者/状态/字数/章节数一起入库 | A 能显示杀虫队队员/完结/1496 章 |

**验收**：发 A 或 B 链接 → 回复使用真实书名；日志不再出现 `《这本小说》`。

## v24.6 · 完结书首次追书误报「没有新章节」

**只修一件事**：新书进度初始化与完结书读取。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 首次追书进度从第 1 章开始，不把最新章节当基准 | 第一读能读到第 1 章 |
| U2 | 完结书走「读已有章节」，不等更新 | A/B 都能返回章节内容或明确的读取失败原因 |
| U3 | 「没有新章节」只在确实追到最新章后出现 | 首次追书不再出现该提示 |
| U4 | 读取失败区分：未登录 / 风控 / 解析失败 / 真无新章 | 日志和回复能区分 |

**验收**：首次追 A 或 B → 不返回「没读成：没有新章节」；能读第 1 章或给出具体失败原因。

## v24.8 · 网络抓包与接口分析（仅自有 / 授权流量）

> 目的：分析**自己的客户端、自己的账号、自己有权访问的内容**，把接口、分页、鉴权和限速记录下来，用于自建客户端/本地阅读器。
> 不做：抓笔趣阁等转载站、绕过付费墙、破解签名/DRM、批量下载后分发。

### 工具

```text
mitmproxy / Charles / Proxyman
Android 模拟器或自有设备安装用户证书
HAR 导出 + 脱敏
```

### 范围

| 允许 | 不允许 |
|---|---|
| 自己的账号登录态 | 他人账号 / 共享账号 |
| 已购买或免费可读章节 | 付费墙后内容 |
| 记录 URL、参数、分页、状态码 | 导出 cookie/token 入库 |
| 复现自己已能发起的请求 | 破解签名、绕过风控 |
| 公开的 Web/API 文档 | 笔趣阁等未授权转载站 |

### 交付物

```text
endpoint 列表：方法 / 路径 / 参数 / 分页 / 返回结构
鉴权流程：登录、刷新、失效（只记流程，不记 token）
限速与错误码：429 / 403 / 验证码
章节 URL 规律与目录分页
脱敏 HAR 样本
```

### 验收

```text
能用自己的账号复现一条已授权章节请求
→ 返回的正文与客户端显示一致
→ 不包含 cookie/token 明文
→ 不下载无权访问的章节
→ 不向第三方分发正文
```

### 红线和停止条件

```text
出现验证码 / 风控 / 封号风险 → 停止
需要破解签名或 DRM → 不做
目标站点是转载站 → 不做
只能拿到付费墙后内容 → 不做
```

## 已放弃：Android App / 转译层

> 结论：不再把手机 App、Android 容器、ARM 转译层作为小说读取方案。
> 原因：APK 仅 arm64；x86 AVD 不能装；ARM64 AVD 在 x86 主机被 emulator 拒绝；转译层需要 Magisk/root，复杂且可能被 App 检测。
> 后续如需读整本，优先考虑用户合法持有的 TXT/EPUB 本地导入，不依赖第三方 App。

## 非目标

- 不重写番茄抓取/OCR；只修搜索、链接解析、进度初始化和异常降级。
- 不保证所有番茄书都能搜到；搜不到时要给出可解释的原因和链接入口。
- 不把四个 bug 合成一个次版本。
