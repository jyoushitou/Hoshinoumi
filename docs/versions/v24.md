# v24 系列 · 插件管理（仅外部插件）

> 前置：v23 多用户 API｜预估 3 天｜**三个次版本**
> 目标：在写各层插件接口之前，先有一个**统一的插件管理器**：
> 清单（manifest）、注册表、安装/启用/停用/升级/卸载、依赖与版本、权限、健康、回滚。
>
> **核心不插件化**：模型/记忆/通道/工具/存储/调度/出站的核心实现保持 native，
> 不注册到这个管理器，不走 manifest / install / disable / uninstall。
> 各层先暴露接口；只有**外部插件**注册到 `PluginRegistry`。
> 以后的模型/记忆/通道/工具/存储/调度/出站七层外部插件，共用一个管理器。

## 为什么先做插件管理

| 没有管理器 | 有管理器 |
|---|---|
| 每层各写一套加载/配置 | 一套 manifest + registry |
| 插件版本/依赖靠人记 | 启动时校验，冲突早报 |
| 停用要改代码/重启 | 运行时 enable/disable |
| 权限散落 | 统一 `permissions` + role 校验 |
| 坏了不知道 | 健康检查 + 失败隔离/回滚 |

## 清单（manifest）

```json
{
  "id": "nao.model.deepseek",
  "name": "DeepSeek Provider",
  "version": "1.2.0",
  "type": "model",                  // model/memory/channel/tool/storage/scheduler/transport
  "entrypoint": "nao_model_deepseek:register",
  "permissions": ["model:call"],
  "requires": {"nao": ">=0.24", "plugins": []},
  "config_schema": { "...": "..." }
}
```

- `type` 决定注册到哪个层；`id` 全局唯一。
- `requires` 做版本/依赖校验；不满足就不加载。
- `permissions` 与角色绑定；`config_schema` 给 UI/CLI 生成配置。

## 关键设计

- **状态表**：`plugins(id, version, type, enabled, config, health, installed_at, updated_at)`。
- **加载**：启动时扫描 `plugins/` + 已安装清单；按 `type` 注册；失败隔离，不影响核心。
- **启用/停用**：运行时切换；停用某层插件时，该层回退到**核心 native 实现**。
- **核心不注册**：核心模型/记忆/通道/工具/存储/调度/出站不是插件，
  没有 manifest，也不出现在 `!plugins` 列表；只能扩展/包装/路由替换。
- **依赖/版本**：语义化版本；循环依赖/缺依赖直接拒绝。
- **权限**：`owner` 可装/停；`admin` 可看/配；`user` 只能用已启用的能力。
- **安全**：默认只允许本地目录/白名单来源；不执行未签名远程代码；插件日志脱敏。
- **回滚**：升级前备份配置/版本；失败自动回滚到上一版。
- **可观测**：`!plugins` 列出 id/type/version/enabled/health；坏插件标红。

## 验收

```bash
!plugins                      # 列表 + 健康
!plugins disable nao.model.deepseek
!plugins enable  nao.model.deepseek
!plugins rollback nao.model.deepseek
```

- 加一个假插件：只写 manifest + 一个 `register()`，不改核心。
- 版本不满足 `requires`：拒绝加载，核心照常启动。
- 停用模型插件：自动用内置默认 provider，不报错。
- 插件 `register()` 抛异常：核心继续跑，`!plugins` 标红。

## 不做

- 不做插件市场/远程一键安装（先本地/白名单）。
- 不做不可信 Python 代码沙箱（插件视为可信；外部工具走 HTTP/MCP）。
- 不让插件绕过 `user_id`/权限直接查库。
- 不把插件管理做成一个层插件；它是**底座**。

## 风险

| 风险 | 处理 |
|---|---|
| 坏插件拖垮启动 | 每个插件隔离加载；失败跳过并告警 |
| 版本冲突 | `requires` 校验；启动拒绝并给出原因 |
| 权限过大 | manifest 声明 + role 校验；默认最小权限 |
| 停用后无实现 | 每层保留内置默认；停用只回退，不空窗 |
| 升级失败 | 备份 + 自动回滚；配置迁移幂等 |
