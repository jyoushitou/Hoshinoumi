# v24 系列 · 插件接口实现（含 v24.4 书籍链路修复）

> 核心：实现第三方插件接入所需的接口和注册表。
> **本层不实现任何功能**：只定义契约和注册表，不提供任何实现；具体 provider / channel / tool / storage 由核心或第三方开发者实现。
> 现有功能仍是核心 native；没有插件时核心默认链路照常工作。
> 欢迎其他开发者按契约提交实现。

```python
class PluginManifest(Protocol):
    name: str
    version: str
    capabilities: set[str]
    priority: int


class PluginRegistry(Protocol):
    def register(self, manifest: PluginManifest, factory) -> None: ...
    def get(self, capability: str, name: str): ...
    def list(self) -> list[PluginManifest]: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v24.0** | `PluginManifest` / `PluginRegistry` 契约 + 内存注册表 | 能注册/查找/列出测试插件 |
| **v24.1** | 能力字符串规范 + 版本校验 + 冲突检测 | 同名/同能力冲突可解释 |
| **v24.2** | 第三方 adapter 加载入口（只加载，不实现具体插件） | 加载失败不影响核心 |
| **v24.3** | 核心 native 不注册测试 + 文档/收尾 | 核心不出现在插件表 |

## 关键约束

- 核心实现不实现 `PluginManifest`，不进入 `PluginRegistry`。
- `get()` 找不到插件时返回 `None`，由调用方走核心。
- 插件注册失败只记录，不阻塞启动。
- 核心功能只能通过启动前 `config/features.json` / `NAO_FEATURES` 关闭。

## v24.4 · 书籍链路回归修复（插单）

> 这是 v24 的回归修复插单，不属于插件接口层；v24.0–v24.3 仍然只做接口/注册表，不实现功能。
> 触发：主人说「去看看十日终焉」→ 搜索无结果 → 被要求给链接；发链接后又把书名识别成「这本小说」，回复「好，我去看《这本小说》」，最后「没读成：没有新章节」。

### 现象

| # | 现象 | 证据 |
|---|---|---|
| B1 | 搜索「十日终焉」无结果 | `[接口] [小说] 搜索「十日终焉」无结果` |
| B2 | 被要求给链接，而不是直接命中 | 8.2 秒后回复「给我个链接吧，我找不到同名的本」 |
| B3 | 链接消息被识别成书名「这本小说」 | `主人点名追书：《这本小说》` |
| B4 | 书已经存在且完结，却回复没有新章节 | 番茄页显示 320.1 万字 / 1496 章 / 完结 / 最近更新 2025-10-31 |
| B5 | 搜图异常拖慢链路 | `ALAPI搜图异常: 'NoneType' object has no attribute 'get'` |

### 根因假设

1. 番茄搜索接口对关键词/编码/风控敏感，`十日终焉` 没有命中；没有直接 URL 兜底。
2. 链接解析只取了 URL，没有解析页面标题；标题回退成了「这本小说」。
3. 追书进度初始化错误：新书第一次读时把「最新章节」当基准，误判为「没有新章节」。
4. 完结书仍按「等更新」逻辑处理，没有走「读已有章节」。
5. ALAPI 返回空结果时没做 `None` 防御。

### 修复单元

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 加回归样本：`十日终焉` 书名 + 番茄链接 `fanqienovel.com/page/7143038691944959011` | 测试不依赖实时网络；用固定 HTML 快照 |
| U2 | 搜索无结果时走番茄搜索页/直接链接兜底，不再只回「给我链接」 | 输入书名能拿到候选或明确失败原因 |
| U3 | 链接解析标题/作者/状态/字数/章节数；标题不能回退成「这本小说」 | 识别为「十日终焉」/「杀虫队队员」/完结/1496 章 |
| U4 | 新书进度初始化：首次追书从第 1 章开始，完结书读已有章节 | 不再出现「没读成：没有新章节」 |
| U5 | 同一本书重复追书幂等，不重复加书架 | 书架只有一本 |
| U6 | ALAPI 空结果 / 缺字段安全降级，不抛 `NoneType.get` | 异常只记 debug，不影响回复 |

### 验收

```text
输入：去看看十日终焉
→ 能命中番茄页面，或给出候选；不再无条件要链接

输入：<番茄链接>
→ 标题 = 十日终焉
→ 作者 = 杀虫队队员
→ 状态 = 完结
→ 章节数 = 1496
→ 不出现《这本小说》

首次追书
→ 从第 1 章开始读
→ 完结书按已有章节处理
→ 不返回「没读成：没有新章节」

重复追同一本
→ 不重复加书架
```

### 非目标

- 不重写番茄抓取/OCR；只修搜索、链接解析、进度初始化和异常降级。
- 不保证所有番茄书都能搜到；搜不到时要给出可解释的原因和链接入口。
