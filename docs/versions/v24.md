## v24.1 · 搜索「十日终焉」无结果

**只修一件事**：番茄搜索命中率。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 固定「十日终焉」搜索 HTML 快照，不依赖实时网络 | 回归测试稳定 |
| U2 | 检查关键词编码、请求头、搜索 URL、结果选择器 | 能拿到候选列表 |
| U3 | 搜索无结果时走番茄搜索页兜底，并给出可解释原因 | 不再无条件回「给我链接」 |

**验收**：输入「去看看十日终焉」→ 能命中 A 页面或给出候选，不直接要求链接。

## v24.2 · 链接标题识别成「这本小说」

**只修一件事**：从番茄链接解析真实书名，禁止回退成「这本小说」。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 链接入库时抓取页面 `<title>` / 作品名节点 | 样本 A/B 都能取到书名 |
| U2 | 标题清洗：去掉「完整版在线免费阅读」「番茄小说」等后缀 | A = 十日终焉；B = 领主：我在苦痛世界，养成少女 |
| U3 | 解析失败时保留 URL 并明确报错，不伪造书名 | 不出现《这本小说》 |
| U4 | 作者/状态/字数/章节数一起入库 | A 能显示杀虫队队员/完结/1496 章 |

**验收**：发 A 或 B 链接 → 回复使用真实书名；日志不再出现 `《这本小说》`。

## v24.3 · 完结书首次追书误报「没有新章节」

**只修一件事**：新书进度初始化与完结书读取。

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 首次追书进度从第 1 章开始，不把最新章节当基准 | 第一读能读到第 1 章 |
| U2 | 完结书走「读已有章节」，不等更新 | A/B 都能返回章节内容或明确的读取失败原因 |
| U3 | 「没有新章节」只在确实追到最新章后出现 | 首次追书不再出现该提示 |
| U4 | 读取失败区分：未登录 / 风控 / 解析失败 / 真无新章 | 日志和回复能区分 |

**验收**：首次追 A 或 B → 不返回「没读成：没有新章节」；能读第 1 章或给出具体失败原因。

## v24.5 · 网络抓包与接口分析（仅自有 / 授权流量）

> 目的：分析**自己的客户端、自己的账号、自己有权访问的内容**，把接口、分页、鉴权和限速记录下来，用于自建客户端/本地阅读器。
> 不做：抓笔趣阁等转载站、绕过付费墙、破解签名/DRM、批量下载后分发。

### 工具

```text
mitmproxy / Charles / Proxyman
Android 模拟器或自有设备安装用户证书
HAR 导出 + 脱敏
```

### 范围

| 允许 | 不允许 |
|---|---|
| 自己的账号登录态 | 他人账号 / 共享账号 |
| 已购买或免费可读章节 | 付费墙后内容 |
| 记录 URL、参数、分页、状态码 | 导出 cookie/token 入库 |
| 复现自己已能发起的请求 | 破解签名、绕过风控 |
| 公开的 Web/API 文档 | 笔趣阁等未授权转载站 |

### 交付物

```text
endpoint 列表：方法 / 路径 / 参数 / 分页 / 返回结构
鉴权流程：登录、刷新、失效（只记流程，不记 token）
限速与错误码：429 / 403 / 验证码
章节 URL 规律与目录分页
脱敏 HAR 样本
```

### 验收

```text
能用自己的账号复现一条已授权章节请求
→ 返回的正文与客户端显示一致
→ 不包含 cookie/token 明文
→ 不下载无权访问的章节
→ 不向第三方分发正文
```

### 红线和停止条件

```text
出现验证码 / 风控 / 封号风险 → 停止
需要破解签名或 DRM → 不做
目标站点是转载站 → 不做
只能拿到付费墙后内容 → 不做
```

## v24.6 · 阅读来源优先级与本地文件回退

> 原则：**优先网络阅读；网络不可用或受限时，不绕过限制，改为提示用户提供本地文件或放进专属文件夹。**
> 本地文件只在本机读取，不上传、不再分发。

### 本地小说阅读声明

本项目只提供本地 TXT/EPUB 的解析与阅读工具，**不提供、不托管、不分发任何小说内容**。本地小说阅读与项目本身的内容提供无关。

- 书籍文件与来源由使用者自行提供；使用者应确保自己拥有合法的阅读、使用和存储权利。
- 本项目不主动获取、不审核、不存储用户的本地书籍内容，对用户放入 `data/books/` 的文件内容不知情。
- 本项目不内置书源，不提供盗版站点适配，不绕过付费墙、DRM 或登录限制。
- 因使用本地文件产生的版权、内容与合规责任，由使用者自行承担。
- 权利人如有异议，请由使用者自行删除相关文件并停止使用。



### 来源优先级

```text
1. 授权的网络来源 / 公开 API / 公版书
2. 用户自己的 TXT / EPUB
3. 用户放进 data/books/ 的文本
```

### 网络受限时

以下情况不重试、不绕过，直接提示：

```text
需要登录 / SVIP
验证码 / 风控
403 / 429
页面结构变化
章节缺失
```

提示文案：

```text
这本书现在读不到（原因：需要登录/受限/解析失败）。
你可以：
1. 把 TXT/EPUB 放到 data/books/
2. 发我文件
3. 换一个你有权限的来源
```

### 本地文件夹

```text
data/books/
  ├── README.md
  ├── 书名.txt
  └── 书名.epub
```

规则：

- 支持 TXT（UTF-8 / GBK 自动识别）和 EPUB
- 文件名即书名，或读取 EPUB 元数据
- 自动分章：`第N章` / `Chapter N` / 空行分隔
- 只读本机，不提交仓库
- 同名文件不覆盖，先提示

### 命令

```text
!books                    列出本地书
!book read <文件名> [章节]  直接读本地文件，不导入数据库
!book next                 下一章
!book progress             当前进度
!book import <路径>        可选：导入索引
```

### 命令直读（不导入）

- `!book read 十日终焉 11`：扫描 `data/books/`，直接读第 11 章
- 不写书架、不建索引、不入库
- 读完只回复**摘要 + 本章开头**，不把全文刷进 QQ
- 章节缓存只在内存，回复后清空
- 只允许 `data/books/` 内的真实路径：
  - 拒绝 `..`
  - 拒绝软链接指向目录外
  - 拒绝绝对路径
- 仅 owner 可用，群聊里不响应
- 首次执行 `!books` / `!book read` 时回复三行声明：本地阅读仅提供解析工具，文件与来源由使用者提供，本项目不提供/不审核/不知情

### 命令直读验收

```text
!book read 十日终焉 11
→ 能读到第 11 章，回复摘要 + 开头

!book next
→ 进入第 12 章

!book read ../etc/passwd 1
→ 拒绝：只能读 data/books/

群聊里发 !book read

```

### 验收

```text
网络可读
→ 直接读，不提示本地文件

网络受限
→ 明确原因 + 提示 data/books/，不绕限制

data/books/ 有 TXT
→ !books 能看到；能分章、能读第 1 章

data/books/ 有 EPUB
→ 能读元数据、目录、正文

没有本地文件
→ 提示路径和格式，不报“没有新章节”
```

## 已放弃：Android App / 转译层

> 结论：不再把手机 App、Android 容器、ARM 转译层作为小说读取方案。
> 原因：APK 仅 arm64；x86 AVD 不能装；ARM64 AVD 在 x86 主机被 emulator 拒绝；转译层需要 Magisk/root，复杂且可能被 App 检测。
> 后续如需读整本，优先考虑用户合法持有的 TXT/EPUB 本地导入，不依赖第三方 App。

## 非目标

- 不重写番茄抓取/OCR；只修搜索、链接解析、进度初始化和异常降级。
- 不保证所有番茄书都能搜到；搜不到时要给出可解释的原因和链接入口。
- 不把四个 bug 合成一个次版本。
