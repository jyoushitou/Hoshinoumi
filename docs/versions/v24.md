# v24 系列 · 插件接口实现（含 v24.4–v24.9 书籍链路修复）

> 核心：实现第三方插件接入所需的接口和注册表。
> **本层不实现任何功能**：只定义契约和注册表，不提供任何实现；具体 provider / channel / tool / storage 由核心或第三方开发者实现。
> 现有功能仍是核心 native；没有插件时核心默认链路照常工作。
> 欢迎其他开发者按契约提交实现。

```python
class PluginManifest(Protocol):
    name: str
    version: str
    capabilities: set[str]
    priority: int


class PluginRegistry(Protocol):
    def register(self, manifest: PluginManifest, factory) -> None: ...
    def get(self, capability: str, name: str): ...
    def list(self) -> list[PluginManifest]: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v24.0** | `PluginManifest` / `PluginRegistry` 契约 + 内存注册表 | 能注册/查找/列出测试插件 |
| **v24.1** | 能力字符串规范 + 版本校验 + 冲突检测 | 同名/同能力冲突可解释 |
| **v24.2** | 第三方 adapter 加载入口（只加载，不实现具体插件） | 加载失败不影响核心 |
| **v24.3** | 核心 native 不注册测试 + 文档/收尾 | 核心不出现在插件表 |

## 关键约束

- 核心实现不实现 `PluginManifest`，不进入 `PluginRegistry`。
- `get()` 找不到插件时返回 `None`，由调用方走核心。
- 插件注册失败只记录，不阻塞启动。
- 核心功能只能通过启动前 `config/features.json` / `NAO_FEATURES` 关闭。

## v24.8 · 番茄登录态与付费墙

**只修一件事**：网页端的「需要登录/SVIP」识别与降级；手机 App 端无付费墙的读取走 v24.9。

### 证据

样本 B 的章节页：

```text
https://fanqienovel.com/reader/7324674633746088510?enter_from=page
第11章 卑鄙，是贵族的通行证
正文只显示几段 → 扫码下载APP免费读 / SVIP网页畅读
```

这不是解析失败，是**未登录/未购买**时的付费墙。

### 方案

| 单元 | 内容 | 验收 |
|---|---|---|
| U1 | 识别付费墙文案/节点：`扫码下载APP免费读`、`SVIP网页畅读`、`购买SVIP` | 能判定「需要登录/SVIP」 |
| U2 | 支持本地 cookie：`FANQIE_COOKIE` 环境变量或 `config/fanqie_cookies.json`（`.gitignore`） | 登录态可注入 Playwright |
| U3 | 不改密码、不存密码；只存 cookie，且日志脱敏 | 仓库/日志无 cookie |
| U4 | cookie 失效/无 VIP 时明确提示，不返回「没有新章节」 | 用户知道是账号问题 |
| U5 | 无账号态时只读免费预览，并标注「仅预览」 | 不把预览当全文 |

### 验收

```text
匿名打开章节页
→ 识别付费墙
→ 回复：需要登录番茄账号/SVIP，当前只能读预览
→ 不出现「没读成：没有新章节」

配置有效 cookie
→ 能读到第 11 章正文（至少已购/免费部分）
→ 日志不出现 cookie

cookie 失效
→ 提示重新登录
→ 不回退成「没有新章节」
```

### 安全

- 不要求用户发密码；只接受浏览器导出的 cookie。
- cookie 文件不提交，`.gitignore` 排除。
- 日志只记「cookie 是否有效」，不记值。
- 不共享账号；只在本机使用。



### 实测记录（2026-11-15）

- `config/fanqie_cookies.json` 可读取：27 条 cookie，成功注入 Playwright。
- 默认 headless 下页面只有 390 字，正文不渲染；加 `--disable-blink-features=AutomationControlled` 后能拿到正文预览。
- 章节页仍出现 `扫码下载APP免费读，SVIP网页畅读`，说明 cookie 登录态没有带来网页全文权限，或账号没有 SVIP。
- 当前 `parse_chapter()` 返回 0：番茄新结构是 `div.muye-reader-content`，旧正则匹配不到嵌套 div。
- 预览正文仍是字体加密字符，不能直接当正文用；全文需要账号/SVIP 或 OCR。

### 追加单元

| 单元 | 内容 | 验收 |
|---|---|---|
| U6 | 支持 `div.muye-reader-content` 新结构；用 DOM 文本而不是非贪婪正则 | 预览正文能解析出来 |
| U7 | Playwright 启动加 `--disable-blink-features=AutomationControlled`，优先用系统 Chrome | headless 不再空白 |
| U8 | 账号有 SVIP 时验证全文；无 SVIP 时只返回预览并明确提示 | 不把预览当全文 |

## v24.9 · 番茄移动端读取（Linux 服务器 Android 容器，实验性）

> 前提：手机 App 端没有网页的 SVIP 付费墙。
> 约束：**不接外部手机、不接外部 ADB**；在 Linux 服务器内跑 Android 容器/模拟器。
> 说明：Waydroid 用 `waydroid shell`，redroid/AVD 用**本机 localhost adb** 作为容器控制通道，不是外接手机。若连 localhost adb 也不能用，就只能走 App API，风险更高。

### 先跑预检

```bash
bash scripts/check_android_worker.sh
```

重点看：

```text
/proc/filesystems 有没有 binder
/dev/kvm 在不在
内存 / CPU
waydroid / redroid / docker / adb / weston 是否安装
```

### 方案优先级（Linux 服务器）

| 顺序 | 方案 | 条件 | 评价 |
|---|---|---|---|
| 1 | Waydroid | binder + Wayland/Weston | 最接近“Linux 跑 Android”，资源较低 |
| 2 | redroid（Docker） | binder + 特权容器 | 无头服务器常用；需要内核支持 |
| 3 | Android AVD | /dev/kvm | 最重；反模拟器风险高 |
| 4 | App API | 不需要容器 | 只在接口稳定、无需破解签名时考虑 |

### 次版本

| 版本 | 内容 | 验收 |
|---|---|---|
| v24.9.0 | 预检 + 选定容器；无头启动；确认能装 APK | `waydroid status` 或 `adb devices` 看到设备 |
| v24.9.1 | 安装番茄 App；用 VNC / `show-full-ui` 手动登录一次 | App 能打开书，登录态持久化 |
| v24.9.2 | 章节读取：UIAutomator dump 取文本，失败则截图 OCR | 能拿到第 11 章正文 |
| v24.9.3 | 翻章、限速、缓存、失败降级、看门狗、资源上限 | 连续 3 章不卡死；失败有原因 |

### 验收

```text
Linux 服务器内启动 Android 容器
→ 安装并登录番茄 App
→ 打开《领主：我在苦痛世界，养成少女》
→ 第 11 章正文可读
→ 能翻下一章
→ 单章 < 30 秒
→ 内存可接受
```

### 放弃条件

```text
服务器没有 binder 也没有 KVM
App 检测模拟器/容器，登录即风控
截图被 FLAG_SECURE
单章 > 30 秒
内存 > 2GB
```

### 边界

- 只用自己的账号，不共享、不卖账号。
- 不做破解签名/绕过 DRM；只做正常 App 的 UI 自动化。
- 优先 Waydroid/redroid；AVD 最后。
- 失败就回到网页预览/OCR，不阻塞聊天。
- 云手机/手机农场不在本项目默认方案内。

## 非目标

- 不重写番茄抓取/OCR；只修搜索、链接解析、进度初始化和异常降级。
- 不保证所有番茄书都能搜到；搜不到时要给出可解释的原因和链接入口。
- 不把四个 bug 合成一个次版本。
