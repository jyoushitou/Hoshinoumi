# v24 系列 · 插件接口实现

> 核心：实现第三方插件接入所需的接口和注册表。
> **本层不实现任何功能**：只定义契约和注册表，不提供任何实现；具体 provider / channel / tool / storage 由核心或第三方开发者实现。
> 现有功能仍是核心 native；没有插件时核心默认链路照常工作。
> 欢迎其他开发者按契约提交实现。

```python
class PluginManifest(Protocol):
    name: str
    version: str
    capabilities: set[str]
    priority: int


class PluginRegistry(Protocol):
    def register(self, manifest: PluginManifest, factory) -> None: ...
    def get(self, capability: str, name: str): ...
    def list(self) -> list[PluginManifest]: ...
```

## 实现步骤

| 次版本 | 内容 | 验收 |
|---|---|---|
| **v24.0** | `PluginManifest` / `PluginRegistry` 契约 + 内存注册表 | 能注册/查找/列出测试插件 |
| **v24.1** | 能力字符串规范 + 版本校验 + 冲突检测 | 同名/同能力冲突可解释 |
| **v24.2** | 第三方 adapter 加载入口（只加载，不实现具体插件） | 加载失败不影响核心 |
| **v24.3** | 核心 native 不注册测试 + 文档/收尾 | 核心不出现在插件表 |

## 关键约束

- 核心实现不实现 `PluginManifest`，不进入 `PluginRegistry`。
- `get()` 找不到插件时返回 `None`，由调用方走核心。
- 插件注册失败只记录，不阻塞启动。
- 核心功能只能通过启动前 `config/features.json` / `NAO_FEATURES` 关闭。
