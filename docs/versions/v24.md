# v24 系列 · 插件接口

> 核心：只定义第三方插件接入的接口，不实现插件，不描述插件功能。
> 插件只能通过接口添加实现；核心功能不插件化。

```python
class PluginManifest(Protocol):
    name: str
    version: str
    capabilities: set[str]
    priority: int


class PluginRegistry(Protocol):
    def register(self, manifest: PluginManifest, factory) -> None: ...
    def get(self, capability: str, name: str): ...
    def list(self) -> list[PluginManifest]: ...
```

规则：

- `PluginRegistry` 只接收第三方插件，核心实现不注册。
- 插件没有权限关闭/卸载核心；核心只受启动前 `features.json` 控制。
- 插件失败由调用方回退核心，不改变核心代码路径。
