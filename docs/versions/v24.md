# v24.0.0 · 刷 B 站

> 前置：v16（小说）+ v24（调度器）｜预估 4~5 天

## 目标

主人不找她的时候，**她自己刷视频**，看到有意思的在群里 **@ 主人** 分享。

## 触发时机

和 v16 共用「空闲」判断：

| 条件 | 说明 |
|---|---|
| 主人 ≥ 2 小时没说话 | 可调 |
| 今天刷得不多 | 每天最多 3 条 |
| 不在深夜 | 01:00~07:00 不刷 |
| 和读书分开计数 | 读书和刷视频各有配额 |

## 包含单元

| 单元 | 条目 | 内容 |
|---|---|---|
| U23 | E1 E3 | B 站拉推荐/关注流 + 看完的评论 |
> 抖音放在 **v25.0**（同一套框架，只换数据源）
| U25 | E4 E5 | 内容过滤、频率、降级、**L3 发评论** |

## 能力分级

| 层级 | 能力 | 可行性 | 风险 |
|---|---|---|---|
| **L1 看** | 拉推荐流，拿标题/简介/字幕/弹幕 | ✅ | 低 |
| **L2 转** | 在群里 **@ 主人** + 链接 + 她的一句话 | ✅ | 无 |
| **L3 评** | 在视频下**发评论** | ⚠️ 能但会封 | **高** |

### L1「真的看过」

| 素材 | 来源 | 说明 |
|---|---|---|
| 标题/简介 | 视频信息接口 | 一定有 |
| **字幕** | CC 字幕接口 | 部分视频有，最接近真看 |
| 弹幕 | 弹幕接口 | 知道观众在吐槽什么 |

**不下载音频**（省流量、避免版权），所以「看」的上限是字幕 + 弹幕。

### L2「转」= 群里 @ 主人

```
[@主人] 你看这个，我今天刷到的
https://www.bilibili.com/video/BVxxxx
```

| 情况 | 行为 |
|---|---|
| 主人在群里且最近说过话 | 在那个群 @ 他 |
| 主人只在私聊 | 退回私聊发 |
| 同一个视频 | 永不重复发 |

### L3 发评论（全自动 + 安全阀）

用户要求全自动。不设人工确认，但硬限制不可绕过：

| 限制 | 值 | 原因 |
|---|---|---|
| 每天最多 | 3 条 | 超过就是刷屏 |
| 同一视频 | 1 条 | 重复=骚扰 |
| 长度 | 5~60 字 | 太短像刷，太长像广告 |
| 连续失败 2 次 | 当天停用 | 大概率风控 |
| `-352`/`-412`/验证码 | 停 24 小时 | 硬告警 |

**已知风险**：B 站发评论需 `csrf`，新号常被 `-352` 拦；抖音需签名，**发评论基本不可行**。账号被判定机器人可能永久限制——**建议用小号跑 L3**。

## 为什么先做 B 站

> 注：起点已在 v16 实测中放弃（章节页对机房 IP + 未登录双重限制）。抖音在 v25.0 单独做。

| 维度 | B 站 | 抖音 |
|---|---|---|
| 公开接口 | 有 | 没有稳定接口，反爬强 |
| 拿到的信息 | 标题/UP/简介/分区 | 基本只有链接 |
| 风险 | 低 | 高 |

抖音只在 `data/credentials.json` 里有 cookie 时启用，且只做 L1/L2。

## 账号与凭据

```
data/credentials.json      # 已在 .gitignore，绝不进版本库
{
  "bilibili": {"sessdata": "...", "buvid3": "...", "bili_jct": "..."},
  "douyin":   {"cookie": "..."}
}
```

- 日志只打前 4 位 + 长度
- `chmod 600`
- **只读优先**：浏览/取信息；只有 L3 才写入

## 内容安全

| 项 | 做法 |
|---|---|
| 分区白名单 | 生活/知识/鬼畜/动画/科技 |
| 屏蔽词 | 政治/攻击/引流/低俗，命中即丢弃换下一条 |
| 频率 | 每天 ≤3 条，冷却 1 小时 |
| 深夜 | 01:00~07:00 不刷 |

## 红线

| 红线 | 原因 |
|---|---|
| 不下载视频 | 流量 + 版权 |
| 不转载封面以外的内容 | 版权 |
| 每天 ≤3 条 | 不是推荐算法 |
| L3 用独立账号 | 封号不牵连主号 |
| 抖音默认关 | 风控代价大 |
