# v42 系列 · 嵌入式前端（Linux 后端）

> 前置：v26 电脑 Web / v41 常驻（后端）/ v24 多端推送｜预估 6 天｜**四个次版本**
> 目标：给一个**常亮的嵌入式前端**——树莓派 + 触摸屏 / 安卓平板，
> 随手能看到对话、能回一句；**后端仍然跑在 Linux 服务器上**。
> 手机在忙、没电、不在手边时，这块屏就是入口。

## 定位：只做前端，不做后端

| 做 | 不做 |
|---|---|
| 登录、会话列表、聊天、发文字/图片 | 不跑模型 |
| 实时 WebSocket、断线重连 | 不跑 MySQL/SQLite |
| 触摸/软键盘/息屏唤醒 | 不跑 QQ/NapCat |
| 开机自启、看门狗、一键烧录 | 不做 LITE 后端、不做 ARM 服务器适配 |

```
嵌入式设备（前端）  ──HTTPS/WSS──▶  Linux 后端（v41）
  树莓派 + 触摸屏                     模型 / 记忆 / DB / NapCat
```

**后端一行不改**：前端只调 v20 网关 / v26 Web 已有的接口；`user_id` 从登录 token 来。

## 硬件选型

| 方案 | 配置 | 结论 |
|---|---|---|
| **树莓派 4B/5 + 7" 触摸屏** | 4 GB / 32 GB TF / Pi OS Lite 64-bit | ✅ 默认 |
| 树莓派 Zero 2 W + 小屏 | 512 MB | 🟡 只做极简聊天，性能紧 |
| 安卓平板 + kiosk | 现成屏幕/电池 | 🟡 备选：不用烧镜像，但后台保活麻烦 |
| ESP32 / MCU | 无浏览器 | ❌ 做不了富文本/图片/输入 |

# v42.0.0 · 硬件与最小镜像

## 镜像

- Raspberry Pi OS Lite 64-bit（无桌面，省内存）
- Chromium kiosk（`--kiosk --noerrdialogs --disable-session-crashed-bubble`）
- 只读根文件系统（可选）：防 TF 卡写坏
- 首次启动进配网/登录页

| 项 | 值 |
|---|---|

| 亮度 | 夜间自动降；触摸唤醒 |
| 息屏 | 5 分钟无操作黑屏；新消息亮屏 |

# v42.0.1 · 前端壳

## 复用

- 直接加载 **v26 电脑 Web** 的构建产物（同一套 UI / 同一套接口）。
- 登录走 v20 网关 JWT；token 存设备 keyring（libsecret / 设备安全存储）。
- 会话/历史/发送/图片全部复用；**不新增业务接口**。

## 设备绑定

- 一台设备绑定一个 `user_id`；换账号 = 退出重登。
- 可选「设备码」：owner 在 Web/桌面生成一次性码，设备输入后绑定，避免在触摸屏上打长密码。

## 触摸

- 大按钮、单列会话、底部输入框。
- 软键盘：`wvkbd` / `squeekboard`（Wayland）或 `onboard`（X11）。
- 图片点开全屏，双指缩放。

## 验收

- [ ] 触摸能登录、翻会话、发文字/图片
- [ ] 中文输入法能打出中文
- [ ] 和手机/QQ 消息双向同步

# v42.0.2 · 嵌入式适配

| 项 | 做法 |
|---|---|
| 开机自启 | systemd user service / autostart 启动 kiosk |
| 看门狗 | 前端进程挂了自动重启；页面白屏自动 reload |
| 断线重连 | WS 指数退避；重连后按 `last_message_id` 补洞 |
| 息屏/唤醒 | DPMS 黑屏；新消息或触摸亮屏 |
| 只读根 | overlayfs，延长 TF 卡寿命（可选） |
| 远程排障 | SSH + 本地日志；不暴露公网 |

## 验收

- [ ] 断电重启后 30 秒内回到聊天页
- [ ] 拔网线 1 分钟恢复，消息不丢
- [ ] 连续 24 小时：内存不涨、页面不白屏

# v42.0.3 · 一键烧录 / 安装 + 收尾

```bash
# 在开发机
./scripts/build_pi_image.sh   # 产出 nao-frontend-pi.img.xz
# 烧录到 TF 卡，开机即可
```

| 步骤 | 内容 |
|---|---|
| 1 | 构建镜像（Pi OS Lite + kiosk + 前端静态资源） |
| 2 | 首次启动配网（Wi-Fi / 有线） |
| 3 | 输入设备码或账号登录 |
| 4 | 自检：后端可达 / WS 连上 / 输入法可用 |

- 烧录文档 + 故障排查表（黑屏 / 连不上 / 输入法 / 时间不对）
- `!status` 增加「前端设备在线」可选项（后端记录设备心跳）

## 验收

- [ ] 全新设备 10 分钟内可用
- [ ] 升级前端只需换静态资源/镜像，不动后端
- [ ] 卸载/重置不删后端数据

## 风险

| 风险 | 处理 |
|---|---|
| Chromium 在 ARM/Wayland 触摸不稳 | 先 X11 兜底；Wayland 单独测 |
| 软键盘遮挡输入框 | 输入框上移；固定底部 |
| TF 卡写坏 | 只读根 + 日志 tmpfs |
| 设备 token 泄露 | keyring + 设备码一次性绑定 + 可远程解绑 |
| 屏幕烧屏 | 息屏 + 夜间降亮度 |
| 后端不可达 | 显示离线；本地缓存最近会话；不假装能发 |

## 不做

- 不在嵌入式上跑后端/模型/DB/QQ/NapCat。
- 不做 LITE 后端模式、不做 ARM 服务器适配。
- 不做多设备同时登录同一账号（先一台）。
- 不做公网暴露；设备只连网关。
