# v36.70 · 随机内容消费

> 空闲时随机选择：读书 / 贴吧 / B站 / 微博 / 知乎。

## 规则

```text
权重可配，读书默认略高
同一 source 不连续选
有冷却
失败/空内容自动换源
不刷屏
```

## 命令

```text
!feed random
!feed tieba
!feed weibo
!feed zhihu
!feed bilibili
!book next
```

## 验收

```text
1. 空闲随机只在五类源中选
2. 同一 source 不连续出现
3. 失败自动换源
4. 自动流程无摘要气泡
5. !feed random 才回摘要
```
