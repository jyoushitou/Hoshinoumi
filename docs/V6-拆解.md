## 1. 第 0 波：零依赖，立刻能做

### U1 说话节奏（4 项）

| 包含 | A1 延迟、A12 分条、A19 沉默短回复、A20 情绪化排版 |
|---|---|
| 依赖 | 无（先用时段 + 随机，接上状态层后再读 mood） |
| 涉及 | `chat/send.py`、`chat/reply.py`、`core/state.py` |
| 验收 | 回复不再秒回；一句话拆 2~3 个气泡；短回复「嗯」能出现 |
| 风险 | 分条太碎会像刷屏 → 群里必配 E29 冷却 |

### U2 反 AI 腔（2 项）

| 包含 | A22 示例对话（few-shot）、A23 反 AI 腔清单、A3 剩余部分（元数据改 JSON 字段） |
|---|---|
| 依赖 | 无 |
| 涉及 | `ai/persona.py`、`ai/prompt.py` |
| 验收 | 连续 10 条回复里没有「不是…而是…」「总而言之」「我理解你的感受」 |
| 备注 | 最便宜、见效最快的一项 |

## 10. 每批的交付要求

1. 一个单元 = 一次提交 = 一份验收记录
2. 改动涉及数据库的（U3/U6/U10），先写迁移脚本 + dry-run
3. 新单元必须补测试，`python3 -m unittest discover -s tests` 保持全绿
4. 单元之间可以并行，但**不要同时改同一个文件**
