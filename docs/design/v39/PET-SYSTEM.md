# v39 游乐园宠物系统（可选）

## 定位

游乐园里的可选玩法：给奈绪/机器人一个可以养的宠物。

```text
默认关闭
用户在游乐园设置里开启
关闭后宠物进入寄养/休息，不再扣需求，数据保留
重新开启后继续
```

宠物属于 v39 世界，不进入聊天核心，不影响主 App。

## 范围

```text
领养 / 起名 / 选择种类
喂食 / 清洁 / 玩耍 / 休息
心情 / 饥饿 / 精力 / 亲密度
疾病 / 恢复（轻量，不做复杂医疗）
奈绪主动照顾宠物
宠物在房间/游乐园内走动
离线推进（上限 24h）
多端同步
```

## 不在范围

```text
不接真实支付
不做宠物对战/抽卡
不做独立宠物 App
不因为宠物死亡永久删除数据
不把宠物需求写进真实存钱
```

## 数据

```text
playground_pets (
  id, user_id, species, name, adopted_at,
  hunger, energy, hygiene, mood, bond,
  health, state, last_tick_at, enabled
)
```

```text
enabled = 0 时：
  不推进需求
  不触发提醒
  不渲染宠物
  数据保留
```

## 交互

```text
游乐园 → 宠物面板
领养 → 起名 → 放进房间
靠近 → 喂食/清洁/抚摸/玩球
奈绪自主：
  宠物饿了会去喂
  宠物脏了会清理
  宠物睡着了不打扰
```

## 经济

```text
只使用游乐园虚拟货币“星砂”
不能充值/提现/转账
不绑定真实存钱
```
