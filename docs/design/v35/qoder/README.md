# Qoder 扩展 Webview 模拟

`qoder-extension.html` 模拟 Qoder 扩展，不是 DSH 插件。

## 入口（三个都能打开）

1. 左侧 Activity Bar 的蓝色 `Q` 图标
2. 左侧扩展图标 `⌘` → Qoder Agent → 打开任务面板
3. `Ctrl+Shift+P` → `Qoder: 打开任务面板`

## 演示

- 点任务切换 Webview 页面
- 新建任务
- Webview 底部发送消息
- Q 图标收起/打开侧栏
- 扩展面板确认已安装
- Esc 关闭命令面板
