# 会话列表二级菜单设计稿（v35.9.35）

> 四份独立整页设计稿，类似 `web/hoshinoumi-web-v35.5.html`。桌面 1440 × 900，手机 390 × 844。

## 四份稿

| # | 文件 | 内容 |
|---|---|---|
| 01 | `01-desktop-private.html` / `.png` | 桌面私聊右键：免打扰 / 删除会话 / 删除联系人 |
| 02 | `02-desktop-group.html` / `.png` | 桌面群聊右键：免打扰 / 删除会话 / 退出群聊；群主退出并解散 |

总览板：`hoshinoumi-conversation-menu-v35.9.35.html` / `.png`

## 交互

```text
桌面：会话行右键 → 菜单；点击外部 / Esc 关闭
手机：会话行从右侧向左滑 56px → 操作栏；再次点击行关闭
私聊：免打扰 / 删除会话 / 删除联系人
群聊：免打扰 / 删除会话 / 退出群聊；群主显示退出并解散
```

## 规则

```text
免打扰只静音通知和未读，不删除会话
删除会话只隐藏入口，QQ 关系和历史保留
删除联系人、退出群聊、群主退出并解散必须二次确认
自定义群直接移除；QQ 群需 NapCat 在线时同步退出
删除联系人需要 NapCat 在线时同步 QQ 好友关系
```

## 消息右键菜单（桌面）

```text
表情回应：👍 👌 ❤️ 😆 😮 😢 ＋
复制 / 转发 / 收藏 / 多选 / 引用
设为精华
撤回 / 删除
```

```text
撤回、删除走确认框
表情回应写入消息下方
引用写入输入框上方
设为精华显示“群精华”标记
转发：选择会话（可多选）→ 生成转发卡片
多选：消息前出现勾选圈 + 底部“已选 N 条”工具栏，可批量转发/删除
```

## 消息菜单（手机）

```text
长按消息 → 表情回应 + 复制 / 转发 / 收藏 / 多选 / 引用 / 设为精华 / 撤回 / 删除
多选：消息前勾选圈 + 底部“已选 N 条”工具栏
转发：底部会话选择 + 发送，当前会话生成转发卡片
撤回/删除：居中确认框
```

## 群权限

```text
群主：退出群聊 = 自动解散；二次确认
群管理：自定义撤回提示（recall_notice）
管理员：群主可设/撤；可撤回群内任意成员消息，撤回前二次确认，系统提示可自定义
普通成员：只能退出
二次确认弹窗：手机端屏幕正中
```
