## 菜单

私聊：

```text
免打扰
删除会话
删除联系人
```

群聊：

```text
免打扰
删除会话
退出群聊
```

## 规则

```text
右键 / 左滑只改变会话入口，不进入聊天
免打扰只静音通知与未读，不删除会话
删除会话只隐藏，QQ 关系和历史保留
删除联系人、退出群聊必须二次确认
手机左滑 48px 展开，再次点击行关闭
```

## 交互标注

```text
桌面：会话行右键，点击外部 / Esc 关闭
手机：左滑露出操作栏，竖向滚动时不触发
删除联系人：提示 NapCat 在线时才同步 QQ 好友关系
退出群聊：自定义群直接移除；QQ 群需 NapCat 在线
```
