## 规则

```text
每个界面必须同时有：正常态 / 空态 / 错误态
关系、存钱等 owner 页面：非 owner 不渲染、不显示入口
金额、私密记忆：仅 owner
列表滚动：页面级容器，底栏不遮挡
浏览器 UI：由真实手机浏览器提供
```
