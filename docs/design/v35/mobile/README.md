## 画板

```text
390 × 844 内为浏览器视口；外侧地址栏/工具栏只做示意
六屏：登录 / 会话 / 聊天 / 记忆 / 关系 / 设置
```

## 页面映射

| 设计屏 | Vue 入口 | 说明 |
|---|---|---|
| 登录 | 登录弹窗 | QQ + owner token，不存密码 |
| 会话列表 | `/chat` | 搜索、私聊/群聊筛选、未读 |
| 聊天 | `/chat` | 消息、输入栏、安全区、输入法避让 |
| 记忆 | `/memory` | 记忆本 / 事件 / 画像 |
| 关系 | `/relation` | 档位与最近变化，不显示精确数值 |
| 设置 | `/settings` | 连接、通知、记忆、关系范围、关于 |

## 浏览器视口规则

这是手机浏览器 Web，不是独立客户端：

```text
不请求全屏，不隐藏浏览器地址栏/工具栏
页面高度用 100dvh，兼容地址栏收放
底部导航在浏览器工具栏上方
safe-area 仅处理刘海/Home Indicator，不假设独占屏幕
滚动容器交给浏览器页面，不用 fixed 全屏壳
```

## 移动端规则

```text
底部导航 69px，含 safe-area
列表项触控高度 ≥ 44px
底部输入栏避开 Home Indicator / 输入法
聊天页滚动区独立，输入栏固定
关系页不显示亲密数值，只显示档位/变化
非主人不可访问财务、私密记忆
```

## 断点

```text
< 430px   手机单栏
430–767px 大屏手机 / 小折叠
≥ 768px   平板两栏，进入 v35.14 平板设计
```

## 交互演示

```text
hoshinoumi-mobile-v35.7-demo.html
```

浏览器直接打开：

- 登录 → 会话列表
- 点奈绪 → 聊天
- 返回 → 会话列表
- 底部导航 → 记忆 / 关系 / 设置
- 聊天输入 → 发送演示消息 → 演示回复
- 设置开关可点击
- 右侧画板可跳任意屏 / 重置

演示数据仅用于确认布局，不代表真实业务。

## 这个 HTML 是什么

独立移动端外观 / 交互设计稿，用于确认移动 Web 的结构、尺寸和触控，不是最终客户端。
