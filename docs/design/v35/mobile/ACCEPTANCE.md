# v35.7 手机 Web 验收

当前只能验收 **v35.7.0.0 手机壳框架**；v35.7.1.0 / v35.7.2.0 还未开始。

## 1. 启动

```powershell
cd integrations/web
pnpm dev --host 0.0.0.0
```

本机：

```text
http://127.0.0.1:27006/chat
```

手机同一 Wi-Fi：

```text
http://<电脑局域网 IP>:27006/chat
```

桌面浏览器可用 DevTools 设备模拟 390 × 844 验收。

## 2. 桌面不回归

窗口宽度 > 820px：

- [ ] 仍是原桌面 AppShell
- [ ] 四栏布局不消失
- [ ] 聊天 / 设置 / 记忆等桌面路由正常

## 3. 手机框架

宽度 ≤ 820px：

- [ ] 出现 MobileShell 顶部栏
- [ ] 登录弹窗可点“稍后配置”进入游客模式
- [ ] 游客显示“游客模式：登录后可同步 QQ 会话”
- [ ] `/chat` 显示会话列表骨架
- [ ] 点会话进入聊天骨架，可返回列表
- [ ] 底部快捷栏显示默认 4 个入口：聊天 / 记忆 / 关系 / 设置
- [ ] 切到 `/memory`、`/relation`、`/settings` 正常

## 4. 快捷栏

- [ ] 收起是一行，4 个入口均分
- [ ] 伸缩标只有箭头，没有“快捷”汉字
- [ ] 展开是 12 个图标入口
- [ ] 展开入口不显示汉字（title 可悬停查看）
- [ ] 点任一入口直接跳转
- [ ] 跳转后自动收起

## 5. 自定义快捷栏

设置 → 底部快捷栏：

- [ ] 默认 4 个
- [ ] 可增加到 5 个
- [ ] 第 6 个被拒绝并提示“最多选择 5 个”
- [ ] 可减少到 1 个
- [ ] 最后一个不能取消并提示
- [ ] 修改后底栏立即变化
- [ ] 刷新页面后选择仍保留
- [ ] 恢复默认可用

## 6. 构建

```powershell
cd integrations/web
pnpm build
```

- [ ] `vue-tsc` 通过
- [ ] Vite build 通过
