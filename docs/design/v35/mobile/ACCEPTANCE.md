# v35.7 手机 Web 验收

设计已于 2026-11-22 封版，见 FREEZE.md。

v35.7.1.0 / v35.7.1.1 / v35.7.2.0 已实现，下面按项验收。

## 1. 启动

```powershell
cd integrations/web
pnpm dev --host 0.0.0.0
```

本机：

```text
http://127.0.0.1:27006/chat
```

手机同一 Wi-Fi：

```text
http://<电脑局域网 IP>:27006/chat
```

桌面浏览器可用 DevTools 设备模拟 390 × 844 验收。

## 2. 桌面不回归

窗口宽度 > 820px：

- [ ] 仍是原桌面 AppShell
- [ ] 四栏布局不消失
- [ ] 聊天 / 设置 / 记忆等桌面路由正常

## 3. 手机框架

宽度 ≤ 820px：

- [ ] 出现 MobileShell 顶部栏
- [ ] 登录弹窗可点“稍后配置”进入游客模式
- [ ] 游客显示“游客模式：登录后可同步 QQ 会话”
- [ ] `/chat` 显示会话列表骨架
- [ ] 点会话进入聊天骨架，可返回列表
- [ ] 底部快捷栏显示默认 4 个入口：聊天 / 记忆 / 关系 / 设置
- [ ] 切到 `/memory`、`/relation`、`/settings` 正常

## 4. 快捷栏

- [ ] 收起是一行，4 个入口均分
- [ ] 伸缩标只有箭头，没有“快捷”汉字
- [ ] 展开是 12 个图标入口
- [ ] 展开入口不显示汉字（title 可悬停查看）
- [ ] 点任一入口直接跳转
- [ ] 跳转后自动收起

## 5. 自定义快捷栏

设置 → 底部快捷栏：

- [ ] 默认 4 个
- [ ] 可增加到 5 个
- [ ] 第 6 个被拒绝并提示“最多选择 5 个”
- [ ] 可减少到 1 个
- [ ] 最后一个不能取消并提示
- [ ] 修改后底栏立即变化
- [ ] 刷新页面后选择仍保留
- [ ] 恢复默认可用

## v35.7.2.0 手机布局 / 安全区 / 输入法

同一个 URL，按视口切换桌面/手机，不做手机专用路径。

| 项 | 检查 |
|---|---|
| 地址栏隐藏/显示 | 使用 100dvh + visualViewport，内容不跳动 |
| 安全区 | 顶部刘海、底部 Home 条不被遮挡 |
| 键盘弹起 | 聊天输入框保持可见，消息区自动滚到底 |
| iOS 输入缩放 | 手机输入框 16px，聚焦不放大页面 |
| 窄桌面 | 431–820px 居中为 430px 手机列，不拉满 |
| 横屏 | 页面不横向溢出，底栏仍可用 |
| 旋转 | 切换横竖屏后布局正常 |
| 桌面回归 | > 820px 仍为 AppShell / 桌面页面 |
| 分页切换 | ≤ 820px MobileShell，无 URL 变化 |
| 搜索 | 会话 / 记忆 / 命令，命中可跳转 |
| 下载 | 图片 / 语音有下载入口 |
| 动画 | 消息入场；减少动态时关闭 |

手动验收：

```text
1. 电脑打开 /chat，缩到 390px → 手机壳
2. 手机打开同一个 /chat → 手机壳
3. 聚焦输入框 → 键盘不遮输入框
4. 旋转横屏 → 无横向滚动
5. 拉回桌面宽度 → AppShell
6. /weekly 同样同一 URL 切换
```
