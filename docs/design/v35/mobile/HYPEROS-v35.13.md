# v35.13 HyperOS 4 深度优化

定位：Android 套壳稳定后，单独的 HyperOS 4 手机客户端，做系统级深度适配。

前置：

```text
v35.8.4 已有基础通知能力（ntfy/UnifiedPush）
v35.8.1.x 已有 Android 权限与后台子页
v35.13 只做 HyperOS 深度能力，不重新造通知
```

范围：

```text
HyperOS 4 设备 profile / 能力上报
Rust 核心 + JNI/NDK
通知渠道 / 常驻通知样式
HyperOS 自启动 / 省电 / 后台保活
深色模式 / 大字体 / 动态取色
桌面小组件 / 服务卡片
包体 / 签名 / 真机兼容
```
