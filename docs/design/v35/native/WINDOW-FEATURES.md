# 深度优化：小窗 / 侧边栏 / 分屏

这些不是普通页面，是各平台原生客户端必须单独做的系统级功能。

## Qt 桌面

```text
托盘 / 快速面板
无边框小窗
置顶 / 画中画
侧边栏 / 双栏
分屏 / 多窗口
```

## HyperOS 手机

```text
自由小窗
全局侧边栏
分屏
悬浮窗
```

## HyperOS 平板

```text
双栏 + 侧边栏
分屏 / 平行窗口
自由小窗 / 悬浮窗
手写笔与键鼠协同
```

## HarmonyOS 2

```text
智慧多窗
悬浮窗
侧边栏 / 分屏
服务卡片
```

## 验收

```text
窗口能开、能关、能恢复
小窗不丢消息/不重复发送
侧边栏状态与主页面同步
分屏尺寸变化不破版
后台回来仍保持窗口状态
没有系统能力时明确降级，不假装支持
```
