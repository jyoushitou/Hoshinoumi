# HarmonyOS 2 原生客户端（v35.15）

定位：鸿蒙 2 真机原生客户端，不套 Android APK、不加载 Vue。

## 技术基线

```text
设备：HarmonyOS 2.x 真机
工程：DevEco Studio，按真机 API 选择 Java UI 或 JS UI（FA 模型）
原生：C/C++ Native API
打包：HAP
```

不使用：

```text
ArkTS/Stage 模型（HarmonyOS NEXT 方向）
WebView/Vue
Android APK 套壳
```

如果真机只允许 Android APK，则归类为 Android 套壳，不能算鸿蒙原生深度优化。
