# 发布路线图（次版本 / 小版本全拆）

> 每个 `x.y` 是一个**次版本**（一组相关能力），每个 `x.y.z` 是一个**可单独发布的小版本**。
> 小版本 = 一次能做完、能验证、能回滚的改动。

## 依赖图

```
v17.0.x ──→ v17.1.x ──→ v17.2.x ──→ v17.3.x
                                        │
                          ┌─────────────┴─────────────┐
                          ↓                           ↓
                     v18.0.x → v18.1.x           v19.0.x → v19.1.x
                                                   │
                                                   ↓
                                              v19.2.x → v19.3.x
```

- **v18 与 v19 互不依赖**，v17 完成后可并行
- v19 内部严格串行（只读 → agent → 写 → 回滚）

## 发布节奏建议

| 周期 | 发什么 |
|---|---|
| 每天 | 1 个小版本（如 v17.0.1） |
| 每个次版本结束 | 观察 1 天再进入下一个 |
| 每个系列结束 | 观察 3 天 + 打 `正式版` |
