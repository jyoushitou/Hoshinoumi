> 每完成一版，按这张表逐项过一遍再打包。
> **测试文件必须跟着改**——尤其是环境相关的（依赖表、环境变量、路径）。

## 1. 代码

- [ ] `python3 -m compileall -q botv` 无报错
- [ ] `python3 scripts/check_names.py` 干净（无未定义名字 / 先用后赋值）
- [ ] `python3 -m unittest discover -s tests` 全绿
- [ ] 新增的模块有对应测试；**改动过行为的模块，测试跟着改**

## 2. 环境相关（最容易忘）

- [ ] **依赖表同步**：`run.py` 的 `REQUIRED_PACKAGES` / `OPTIONAL_PACKAGES` / `AUTO_OPTIONAL_PACKAGES`
  与 `scripts/preflight.py` 的 `REQUIRED` / `OPTIONAL` 一致
- [ ] **环境变量登记**：新增的 `os.getenv("NAO_*")` 加进下面的表，并把默认值写清楚
- [ ] **数据库迁移**：改了表结构就必须有 `scripts/migrate_vN.py`，并且幂等、默认 dry-run
- [ ] **预检能跑**：`python3 scripts/preflight.py` 13 项全过（含环境变量、能力自检、网络连通）

## 为什么单独列「环境相关」

这几类东西**写错了不会立刻报错**，只会在换机器、换 Python 版本、别人 clone 时才炸：

| 类型 | 典型事故 |
|---|---|
| 依赖表 | 新包忘了加进 `run.py`，别人装完跑不起来 |
| 环境变量 | 换了名字没同步文档，配置不生效但没人知道 |
| 数据库迁移 | 代码先上线、迁移没跑 → `Unknown column` |
| 路径 | 用了绝对路径，换机器就找不到文件 |

这几项每次都要过，宁可多花五分钟。
