## 2. 分组明细

### H｜频率与节奏（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| H1 | 发图择时 | 不是每条都配图。AI 给出图片关键词后仍要过概率：基础 30%，同一人 10 分钟冷却一张，群里 20%，心情差 ×0.5。当前是「找到就发」 |
| H2 | 主动频率自适应 | 记录「主动后 30 分钟内是否收到回复」；连续 3 次没回应 → 掷骰基础概率 ×0.5（下限 0.5，不归零）；有回应每次 +10% 回升 |
| H3 | 语音择时 | 与 H1 同源：语音条不每句都发，按场景 + 概率挑时机 |

### I｜解析与精度（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| I1 | 日程解析扩展 | 现在只认「明天/后天/周X/MM月DD日/今晚N点」；补「下个月」「月底」「这周末」「下午稍晚」等模糊说法 |
| I2 | 记忆指代词误伤 | 目前只要出现「之前/上次」就附加「记不清就说记不清」的提示，正常叙述也会被误伤；改成仅在检索为空时附加 |
| I3 | CLIP 残留清理 | `clip.py` 归档到 `deprecated/`，`CLIP_IMAGE_TAGS` 降级为注释，确认全仓库不再引用 |

### J｜待讨论方向（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| J1 | 多用户关系隔离 | 亲密度按 QQ 分开，但生活事件是全局的；「她今天心情不好」要不要对所有人生效 |
| J2 | 记忆冲突处理 | 同一个人说了矛盾的两件事（「我戒烟了」→「我又抽了」），现在两条并存；要不要做冲突消解 |
| J3 | 长会话压缩 | 对话超过 15 轮后旧内容直接丢弃；要不要做「每 10 轮压成一句摘要」 |
