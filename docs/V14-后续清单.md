## 2. 分组明细

### A｜人设与可定制（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| A1 | 人设卡片化 | 把人设从代码里剥出来，变成一个可替换的「角色卡」目录：`personas/nao/`。卡里包含人设正文、称呼、口癖、世界观、few-shot 示例。启动时按配置加载，默认用内置的友利奈绪。别人 clone 下来放自己的卡就能换成自己的角色 |
| A2 | 生活/日记模板随卡走 | 生活事件模板、日记口吻、状态基线（mood/energy/lonely 的初始值和回归速度）都从角色卡读；换角色时这些一起换，不然会出现「换了个角色还在说学生会」 |
| A3 | 多角色切换 | 同时加载多张卡，按 QQ/群切换；需要一套「当前角色」的运行时状态，属于 v15+ 的活 |

**A1 的拆分（真正要动的文件）**

| 现在 | 变成 |
|---|---|
| `ai/persona.py` 里的 `LOCAL_SYSTEM_PROMPT` 大字串 | `personas/nao/prompt.txt`（带 `{now}` `{tone}` 等占位符） |
| `personality_supplement.txt` | `personas/nao/supplement.txt` |
| `CLIP_IMAGE_TAGS`（600 个图片标签） | `personas/nao/tags.txt` |
| `life/events.py` 的 105 条模板 | `personas/nao/life.txt` |
| `life/state.py` 的 `BASE` | `personas/nao/state.json` |
| 硬编码的称呼（「主人」） | 卡里的 `master_title` 字段 |

加载顺序：`NAO_PERSONA` 环境变量 → 配置里的路径 → 默认 `personas/nao/`。
任何一项缺失就用内置默认值，**加载失败不崩**。

### B｜频率与节奏（4 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| B1 | 发图择时 | 不是每条都配图。AI 给出图片关键词后仍要过概率：基础 30%，同一人 10 分钟冷却一张，群里 20%，心情差 ×0.5。当前是「找到就发」 |
| B2 | 主动频率自适应 | 记录「主动后 30 分钟内是否收到回复」；连续 3 次没回应 → 掷骰基础概率 ×0.5（下限 0.5，不归零）；有回应每次 +10% 回升 |
| B3 | 语音择时 | 与 B1 同源：语音条不每句都发，按场景 + 概率挑时机 |
| B4 | @ 也要判断回不回 | 现在被 @ 是必回（只留 3 秒防连点）。改成也要过一次判断：被 @ 的基础概率高得多（建议 75%，没被 @ 是 20%），但仍然可以「已读不回」——深夜、刚回过、连续被刷屏、心情极差时不回。风险是被 @ 不回会让人觉得机器人坏了，所以必须低频、且有明确理由（日志要能说明为什么没回） |

### C｜解析与精度（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| C1 | 日程解析扩展 | 现在只认「明天/后天/周X/MM月DD日/今晚N点」；补「下个月」「月底」「这周末」「下午稍晚」等模糊说法 |
| C2 | 记忆指代词误伤 | 目前只要出现「之前/上次」就附加「记不清就说记不清」的提示，正常叙述也会被误伤；改成仅在检索为空时附加 |
| C3 | CLIP 残留清理 | `clip.py` 归档到 `deprecated/`，`CLIP_IMAGE_TAGS` 降级为注释，确认全仓库不再引用 |

### D｜待讨论方向（3 项）

| 编号 | 功能 | 说明 |
|---|---|---|
| D1 | 多用户关系隔离 | 亲密度按 QQ 分开，但生活事件是全局的；「她今天心情不好」要不要对所有人生效 |
| D2 | 记忆冲突处理 | 同一个人说了矛盾的两件事（「我戒烟了」→「我又抽了」），现在两条并存；要不要做冲突消解 |
| D3 | 长会话压缩 | 对话超过 15 轮后旧内容直接丢弃；要不要做「每 10 轮压成一句摘要」 |

### E｜阅读与视频（7 项｜v16 小说 / v17 视频）

| 编号 | 功能 | 说明 |
|---|---|---|
| E1 | 刷 B 站（v17） | 用 B 站公开接口取热门/排行（标题、UP 主、简介、时长），每天挑 1~3 条当「今天看的」。写进 `events(kind='life')`，标签带分区和 UP 主，聊天时能提「今天刷到个视频…」 |
| E2 | 刷抖音（v17） | 抖音没有稳定的公开接口，反爬强。默认**关闭**：优先做「你发链接给她看」，或接第三方 API（可配置）。不要为了刷抖音把账号/IP 搭进去 |
| E3 | 看完有话说（v17） | 只拿标题/简介级信息，用她自己的口吻评论（「这 UP 主讲得还行」），不转载内容、不剧透。分享不是每看必说，按状态和话题命中 |
| E4 | 内容安全与频率（v16/v17 共用） | 分区白名单（生活/知识/鬼畜/动画）+ 屏蔽词表；每天最多 3 条；只取文字信息，不下载视频 |
| E5 | 发评论（v17） | B 站全自动发评论：每天 ≤3 条、同视频 1 条、连续失败即停。需 csrf，风控强，建议小号；抖音发评论不可行 |
| E6 | 读小说（v16） | 番茄 / 起点：拉免费章节 → 存「书名+进度+最近一章摘要」；不存全文、不碰付费章 |
| E7 | 聊小说（v16） | 记得看到第几章、喜欢哪个角色；聊天时能接剧情，**不剧透**到主人没读到的地方 |
| E8 | 读到有意思的会分享（v16） | 读完一章 20% 概率说一句，3 小时冷却，深夜不说 |
