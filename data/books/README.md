# data/books/

本地 TXT / EPUB 阅读目录。

## 声明

本项目只提供本地 TXT/EPUB 的解析与阅读工具，**不提供、不托管、不分发任何小说内容**。
书籍文件与来源由使用者自行提供；请确认你拥有合法的阅读、使用和存储权利。

## 支持

- `.txt`：UTF-8 / GBK / GB18030 自动识别
- `.epub`：标准 EPUB（读取 OPF 目录与 XHTML 正文）

## 命令

```text
!books                    列出本地书
!book read <文件名> [章节]  直接读，不导入数据库
!book next                 下一章
!book progress             当前进度
```

限制：

- 只读 `data/books/` 内的真实文件
- 拒绝 `..`、绝对路径、指向目录外的软链接
- 每次只回复摘要 + 开头，不把全文刷进 QQ
- 仅主人可用，群聊不响应
- 不写书架、不建索引、不上传
