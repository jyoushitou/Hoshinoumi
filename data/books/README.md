- 书籍文件与来源由使用者自行提供；使用者应确保自己拥有合法的阅读、使用和存储权利。
- 本项目不主动获取、不审核、不存储用户的本地书籍内容，对用户放入 `data/books/` 的文件内容不知情。
- 本项目不内置书源，不提供盗版站点适配，不绕过付费墙、DRM 或登录限制。
- 因使用本地文件产生的版权、内容与合规责任，由使用者自行承担。
- 权利人如有异议，请由使用者自行删除相关文件并停止使用。

# 本地书库

把你自己合法持有的 TXT / EPUB 放在这个目录，bot 只在本机读取，不上传、不再分发。

## 支持

```text
书名.txt
书名.epub
```

- TXT：UTF-8 / GBK 自动识别
- EPUB：读取元数据、目录、正文
- 文件名即书名；EPUB 优先用元数据
- 自动分章：`第N章` / `Chapter N` / 空行分隔

## 命令

```text
!books                 列出本地书
!book import <路径>     导入一本
!book read <书名> <章节>
!book progress         当前进度
```

## 注意

- 这个目录下的书不会提交到 git
- 不要放盗版站抓下来的整本内容
- 只放你有权阅读的文本
